## Record Lock
记录锁, 锁住的是一条数据, 其实就是行锁 S  X

## Gap Lock
间隙锁, 主要功能是解决幻读问题, 重温一下, 幻读是**同一个事务**在两次**相同范围查询**的结果不同, 而这个不同是针对数据的数量而非内容, 比如多一行少一行数据, 或者特指insert 和 delete 操作, 当然update操作应该是一次delete 和一次insert 当然也不允许
而间隙锁就能阻止其他事务在存在间隙锁的区间插入或删除( **但是好像只有多数据了被官方标记为幻读, 少数据和数据修改属于不可重复读** )
间隙锁的阻塞规则, 先确认插入的数据的位置, 然后看这个位置的后一行数据上是否有间隙锁, 有则不可插入, 没有可以插入

## Next-Key Lock
临键锁, 其实就是 Record Lock 加 Gap Lock 一起发挥作用, 也就是有的语句会同时创建两个锁, 我们直接叫做临键锁了
