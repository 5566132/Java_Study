2.利用or关键字可能会导致索引失效, 但是不是一定失效, 
比如 有索引abc 
a = 10 && (b = 10 or c = 10)这个语句其实是两个条件, 
a = 10 && b = 10 或 a = 10 && c = 10  这样会先分别判断再考虑是否要用索引, 以及用什么索引 这个就会优化成用a索引, 然后索引下推去匹配条件
但是要是(a = 10 && b = 10) or ( b = 10 && c = 10)
大概率就优化成全表扫描, 索引失效了

**联合索引, 范围查询**
这个有一个很值得说的点, 对于a b c索引
a = 10 && c = 20 && b < 20 
首先b < 20 会把索引截断, 也就是这个条件导致c字段没法走索引
这个过程就是先索引筛选a = 10的字段, 然后 b 索引筛选出第一个 b < 20的索引, 这个时候开始索引全扫描用c = 20 去筛选字段, 而这个全扫描筛选c的过程叫做 ICP 也就是索引下推
