利用模糊匹配去得到User的简单视图, 
/search/users?name=xxx
但是要求分页, 因为可能匹配很多User


用户点击简单视图触发单用户查询这个时候要返回用户的另一个视图
有id, name, 所有的文章信息, 文章下面还有评论
这个时候就发现, 文章是要分页展示的, 文章是要利用文章表中的user_id字段去和id匹配的
所以, 选择多发几个请求, 去返回文章信息并实现分页
/user/{id} 返回用户简单视图
/articles?page=xxx&size=xxx 返回文章的简单视图,并且是分页展示

接着这个时候可以点击文章详细查看文章, 也就是触发
/article/{id} 单id查询文章, 这个时候就直接复用先前那个就好了, 里面也有评论了
