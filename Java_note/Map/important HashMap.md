这个就是Map接口下的一个类, 这个比较像cpp里面的multimap
特点就是最普通的Map结构, 可以用Key访问Value, 这个访问顺序是和添加顺序不一样的

底层用数组(形成一个哈希桶), 链表(处理哈希值相同的点), 红黑树(当链表过长会自动转变成,带有链表指针的红黑树); 给这个红黑树加入指针结构是为了之后还能退化成链表

用HashMap的时候要在类里面重写两个方法
一个是 equals();   一个是 hashCode();
前者是能在hash值相同的时候去对比键值确定是否是同一个键,
后者则是保证能根据成员计算hash值, 而非按照地址计算
访问时间复杂度为O(1);

补充
HashMap内部有个静态内部类( Node )实现了Entry这个接口,
这就是为什么调用entrySet可以创建一个能被Entry接口类型接收的的Set集合
详情可以看 [[important Entry Map系列遍历方法]]


再补充:
HashMap用红黑树解决哈希冲突而非 平衡搜索二叉树(AVL)
平衡二叉搜索树:就是在二叉搜索树(就是左子树小, 右子树大)的基础上加了平衡条件, 任意节点的左右子树的高度差不能超过1, 超过就会进行左旋或者右旋
红黑树的优势就在于, 红黑树触发自旋的条件更宽松, 但是会保证树的顺序, AVL条件太严格, 很容易触发自旋
