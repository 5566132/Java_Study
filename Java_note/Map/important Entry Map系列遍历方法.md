在这里,我再叙述一遍接口这个玩意的特殊性, 主要是第一个方法会涉及到
首先 Entry 是接口 而且是存在于Map的接口 -> 被叫做嵌套接口
**如果你想要使用一个接口类型的变量那你就只能用这个接口的实现类的对象作为右值**
也就是Entry\<K, V> e = 实现了这个接口的类的对象  
{
先说对这部分的理解, 接口跟类有相似之处, 但是某些特性导致了某些结果
首先接口不能创建对象, 这就导致接口类型接收不到本类型的对象
但是实现了接口的类是可以创建对象的, 而**多态只对类型的继承关系有限制**, 对类型完全没限制, 所以你要转变一个思想, 就是把接口看作一个类, 把实现这个行为看作继承
这样接口的特殊性完全就可以理解成 一个没法创建对象的父类想要创建这个类型的变量只能利用多态的规则去接收继承了这个父类的子类的对象

}

HashMap.Node 和 TreeMap.Entry都实现了这个接口,
