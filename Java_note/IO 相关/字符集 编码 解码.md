字符集就是一个映射表, 把各种语言的符号与特定的数字对应, 以便可以用二进制表示
换句话说, 这就是一套映射规则

编码(解码)格式就是按照某个规则把二进制的数据按字节编码成字符, 
一般字符集都有其对应的编码格式, 而且不通用
比如 UniCode 字符集就对应 UTF-8 这个系列的编码格式, 用GBK格式就会出现乱码
同样, GBK 也有它的字符集(就叫GBK字符集) , 必须要用GBK编码格式

一般文本是用的Unicode的字符集, 也有GBK
所以读取文本最好要指定一下编码的格式(比如UTF-8)这样才能把文本转变成正确的字节形式, 然后再用同样的格式去解码, 把二进制(或者说字节流)转变成文本

比如有如下文本: Hello.txt  编码格式是UTF-8
Hello, world!
你好, 世界!
中文和英文都存在这个不影响什么, (其实各种编码格式对英文都是没影响的, 主要是其他语言的字符)
