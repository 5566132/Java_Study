先说这个ArrayList(集合)就跟vector差不多, 这个是利用 **泛型** 实现可以装任何的数据类型(其实它只能装类), 但是基本数据类型被特殊的包装成了类
其他的都是把首字母大写, int -> Integer       char  ->  Character
也就是说, 你想用集合装int就要在<>里面写Integer
ArrayList<类> V = new ArrayList<>();

V.get(i) 访问下标i的值
V.size();  返回集合的大小
V.add(类) 添加类

删除元素
boolean V.remove(对象);  删除第一个与所指定对象匹配的那个元素
类 V.remove(下标);  按下标删除

修改元素
V.set(下标, 对象);  把该下标的元素修改为指定的元素
