一说到接口, 这个东西就是用来规范行为的, 一般这里会写一些和行为有关的方法(比如游泳, 跑步,)而不是像类那样去规范一种事物

接口这个东西感觉和 类差不多, 但是用途和内容有些差别
首先 子类继承接口的时候我们不说继承, 而叫做 "实现", 要用关键字 implements
而且一个子类能实现多个接口(一个子类只能继承一个类)
接口里面只有三个关键字 public abstract(你写public 或者 不写都是默认这个)
default, static
也就是说, 接口里面默认会存抽象方法, 实现的时候要在子类重写
再说几个小细节, 接口内部可以写变量, 但是只能是常量(也就是final修饰)
			接口内部可以写私有方法, 但是这个写成私有的一般就只为内部的default或者static方法提供便利, 而非外部使用
