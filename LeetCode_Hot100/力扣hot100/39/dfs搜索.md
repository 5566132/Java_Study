这题就是简单的dfs搜索
至于非要用dfs是因为这个要求把具体的组合也罗列出来, 而非只要求计算出总的组合数
可以多次重复使用同一个数去拼凑出target
那么直接在dfs中**实现这个多次重复使用同一个数**即可
实现方法就是先计算当前的总和sum与target之间的dis, 如果dis可以容纳当前遍历到的这个数那就把它加入集合, 然后更新sum, 再次dfs但是不让数组下标移动, 也就是重复使用当前数, 
```
if(sum + n <= target){
            temp.add(n);
            sum += n;
            dfs(candidates, now, target);
            temp.remove(temp.size() - 1);
            sum-=n;
        }
```
这部分就是去实现 : 尝试添加当前数, 然后dfs, 然后移除当前数, 目的是为了之后的情况做准备, 
之后还要有添加下一个数的dfs, 

这两个dfs在每个数都被正常添加的基础上,达到了单个数可以被添加多次的效果
也就是图示部分是尝试添加当前数, 另外一个dfs是移动下标
