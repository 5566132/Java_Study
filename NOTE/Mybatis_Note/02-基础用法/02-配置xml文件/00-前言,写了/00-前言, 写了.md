这个玩意又要学一堆语法, 真服了, 算了学吧, 看起来也不是很多, 这里先说一下框架部分
```
<?xml version="1.0" encoding="UTF-8" ?>  
<!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN" "http://mybatis.org/dtd/mybatis-3-mapper.dtd">  
<mapper namespace="com.atguigu.mybatis.mapper.cus_order.CustomerMapper">  

</mapper>
```
前三行是必备且一样的

\<mapper namespace="接口引用"
这个指定当前xml要去实现哪个接口, 可以这么理解吧, 因为Mybatis就是依靠JDK代理实现的呀
而Mybatis只需要写个接口和xml配置文件就能实现接口中的方法

无所谓, 重点是通过这个方法指定好当前xml映射的接口
**一个xml只能去映射一个接口**
