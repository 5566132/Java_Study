# 映射
将返回值字段从当前类Order转成我在xml里面自定义的类型, 
我直接附上具体实现
```
<select id="getOrderById" resultMap="OrderMp">  
	select  o.* ,  
	        c.id c_id,
	        c.customer_name,
	        c.phone    
	    from t_order o left join customer c on o.customer_id = c.id where o.id = #{id}
</select>  
# 这就是一个外连接查询, 会获得指定id的order的所有字段和这个order对应的customer的所有字段
# 这些customer的字段就是我要封装到customer类中的
  
<resultMap id="OrderMp" type="com.atguigu.mybatis.bean.cus_order.Order">  
    <id column = "id" property = "id"></id>  
    <result column="address" property="address"></result>  
    <result column="amount" property="amount"></result>  
    <result column="customer_id" property="customerId"></result>
    
    <association property="cus" javaType="com.atguigu.mybatis.bean.cus_order.Customer">  
        <result column="c_id" property="id"></result>  
        <result column="customer_name" property="name"></result>  
        <result column="phone" property="phone"></result>  
    </association></resultMap>
```

## \<resultMap 内部的写法
首先看名字, resultMap 结果映射, 明显, 这个关键字是用来指定 结果( 也就是select语句查询出来的行数据 ) 跟别的东西的映射关系的 , 这个是重点
而就事实而言 , 也的确是这样, 这关键字内部都是 comlun="" property=""的形式, 正好是字段映射变量

id 和 result 的区别在于id指定主键, result 指定非主键
\<id colum = "id" 你应该有印象, 数据库中的每个字段的的英文名就是colum 所以这个部分就是指定数据库中的字段名, 准确说是 colum是用来干这个的
property = "id" 这个应该比较熟悉, 用来指定java类中的成员名的
**所以\<? comlun = "" property = "">\</?> 这个部分就是用来建立数据库中字段和java类中成员的映射关系的**
