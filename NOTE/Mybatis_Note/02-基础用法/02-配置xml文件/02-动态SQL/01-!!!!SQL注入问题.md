## 什么是SQL注入问题
假设你使用动态sql让用户自己输入某些位置的关键sql
比如where id = ? 中的?部分
那么如果你只是单纯的把用户输入的东西像拼接字符串一样拼起来会发生问题
比如, 用户传递的是 1 or id = 2 会发生什么, 条件变成 where id = 1 or id = 2 
这明显不符合我的希望, 甚至会产生很严重的后果, 这就是SQL注入问题

因此, 出现了两种注入方式 # 和 $
算了, 我有点不太理解这里, 先粗略说一下使用场景吧
