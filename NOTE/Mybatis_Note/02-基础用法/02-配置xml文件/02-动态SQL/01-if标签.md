比如根据多个字段查询员工的场景, 有时候可能有的字段是null, 也就是不需要这个字段
那如果像之前那样拼接, 只能把参数填进去, 那不就成了查找这个参数为null的行了吗, 不对
你的确可以在java代码中判断, 但是那样代码会变复杂, 所以直接用动态sql即可
比如根据age 和 salary查询
```
<select id="接口方法名" resultMap="自定义映射集合">  
    select * from t_emp  where 1=1
        <if test="name != null">  
            emp_name = #{name}  
        </if>  
        <if test="salary != null">  
            and emp_salary = #{salary}  
        </if>  
        
</select>
```
这个还是比较丑陋了, 因为光用if它只能起到满足条件将内容拼接在sql后面, 不能更灵活些, 如果不写where 1=1 只写一个where 那如果只有第二个if成立就成了 where and....这是非法sql
