这依旧是个框架, 要导入依赖, 还要配置文件,
配置文件直接写在application.yaml就行
```
# springdoc-openapi项目配置  
springdoc:  
  swagger-ui:  
    path: /swagger-ui.html  
    tags-sorter: alpha  
    operations-sorter: alpha  
  api-docs:  
    path: /v3/api-docs  
  group-configs:  
    - group: 'default'  
      paths-to-match: '/**'  
      packages-to-scan: com.atguigu.rest.crud.Controller  
# knife4j的增强配置，不需要增强可以不配  
knife4j:  
  enable: true  
  setting:  
    language: zh_cn
```

这个东西是半自动的框架, 虽说不用在Dao层实现业务逻辑了, 但是需要配置xml文件去进行sql语句的书写, 结果映射啥的
