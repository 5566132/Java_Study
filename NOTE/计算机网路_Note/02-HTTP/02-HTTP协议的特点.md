1.双向协议, 重要特点
**HTTP协议是固定会按照一次请求一次响应的方式去让客户端和服务端交互的**
但前提是端到端建立了TCP连接通道, 要是通道都没建立就没法谈是否发送了报文了
那就有问题了, 404之类的东西不是发送失败了吗, 那岂不是只有发送端, 没有响应端, 
对于这个问题, 其实端到端已经建立了TCP连接, 并且发送了HTTP报文, 而404就是一种响应报文, 所以符合 1对1

2.超文本
意思就是这个报文可以发送的东西不只有文本, 还有图片, 音视频等, 但是都是按照二进制形式去发送的
有几个常见的状态码可以自己去看看, 就是404那些东西, 大部分接触的时候都是用浏览器输入网址, 然后看见这些状态码, 事实上, 报文发送出去了, 服务端也回应了, 这个状态码就是服务端响应给客户端的报文, 告知客户端本次响应的状态, 比如404就是告诉客户端, 客户端出问题了
