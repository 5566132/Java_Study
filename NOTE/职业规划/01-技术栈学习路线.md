**🔴 不用补的（已确认用不到，别回头）**：网络编程、压缩流、IO 52-59、斗地主案例、GUI 深化。

### 档 1.5 · Java 8 函数式补漏（🔴 立即执行 · 3-5 天）

> **为什么必须现在补**：MyBatis-Plus 的 `LambdaQueryWrapper`、项目里的 `list.stream().map().collect()`、`Optional` 判空，全是这套。现在花几小时，后面省几十小时。

**学什么**：
- 🔴 **Stream 流**：创建（`stream()` / `Stream.of()`）、中间操作（`filter`/`map`/`distinct`/`sorted`/`limit`）、终结操作（`collect(Collectors.toList()/toMap()/groupingBy())`/`forEach`/`count`/`reduce`/`anyMatch`）
- 🔴 **方法引用 `::`**：静态方法引用、实例方法引用、构造器引用（`String::new`）
- 🔴 **Optional**：`ofNullable` / `orElse` / `orElseThrow` / `map` / `ifPresent`
- 🟡 `Stream` 的惰性求值（为什么没有终结操作就不执行）

**怎么学**：随便找个"Java8 新特性 2 小时"视频 + 自己写 demo（用 Stream 把 `List<Emp>` 按部门分组求平均薪资）。

**过关**：不看笔记能把一个 `List` 用 Stream 转成 `Map` 并按条件过滤。

### 档 2 · 集合框架源码（必会，Java 面试王炸区）

> 面试最爱问**底层实现**，不是用法。这是和"培训班只会调用"拉差距的关键。

**学什么**：
- 🔴 **HashMap**（最高频，必讲透）：
  - 底层结构：数组 + 链表 + 红黑树（什么时候树化、为什么 8/6）
  - put 流程：hash 扰动 → 定位 → 冲突 → 扩容（2 倍、阈值 0.75、为什么）
  - 为什么线程不安全、JDK7 头插死循环问题
- 🔴 ArrayList vs LinkedList：底层数组/双向链表、扩容机制、各自增删查复杂度
- 🟡 ConcurrentHashMap：**JDK8 为什么放弃分段锁改用 CAS + synchronized**（大二下学并发时再补，先标记）
- 🟡 HashSet / TreeMap：红黑树、自然排序/比较器
- 🟡 迭代器 fail-fast 机制（modCount）

**怎么学**：读源码（IDEA 里 F4 进源码），配合"HashMap 源码"面经文章；画 put 流程图存 Obsidian。

### 档 1 · TCP/IP 基础（必会）

**学什么**（按此顺序）：
- 🔴 OSI 七层 → TCP/IP 四层，每层负责什么、典型协议
- 🔴 **TCP 三次握手**：为什么不是两次/四次、**状态变化**（SYN_SENT/ESTABLISHED...）、SYN 泛洪攻击
- 🔴 **TCP 四次挥手**：为什么是四次、TIME_WAIT 为什么存在（2MSL）、大量 TIME_WAIT 怎么处理
- 🔴 TCP vs UDP：各自特点、场景、可靠传输靠什么（序列号/确认/重传）
- 🔴 流量控制（滑动窗口） vs 拥塞控制（慢启动/拥塞避免/快重传/快恢复）
- 🟡 粘包/拆包、TCP 保活机制、半连接队列 vs 全连接队列

### 档 2 · HTTP/HTTPS（必会）

**学什么**：
- 🔴 HTTP 报文结构、常见状态码（2xx/3xx/4xx/5xx 各举几个）
- 🔴 GET vs POST、HTTP 无状态怎么保持（Cookie/Session/Token）
- 🔴 HTTP/1.1 vs 2.0：队头阻塞、多路复用、二进制分帧、HTTP/2 还有没有队头阻塞
- 🔴 **HTTPS 握手全流程**：CA 证书 → 非对称换对称密钥 → 加密通信，证书怎么防篡改
- 🟡 HTTP/3（QUIC，基于 UDP）一句话了解
- 🔴 **经典大题"浏览器输入 URL 到页面显示发生了什么"**（必背，DNS→TCP→HTTP→渲染 全链路）

**怎么学**：**首选小林coding 图解网络**（免费，专为面试八股）→ 视频版 B 站"湖科大教书匠"（动画演示绝佳）/ "韩立刚"（就业向）。**只看 TCP/HTTP 章节**，每层画时序图存 Obsidian。

> 面试重点答题框架见 [[11-数据库面试重点]]，学习深度分档见 [[07-MySQL学习深度]]。

面试考底层，不是语法。**完整分档清单见 [[07-MySQL学习深度]]**，这里只放核心目标和顺序。

**一句话**：主力学到「第 5 档 InnoDB 底层 + 日志」，第 6 档只了解名词。

**核心目标（按序）**：
1. 🔴 **索引**（第 1 优先）：B+树为什么、索引失效 ≥5 条、最左前缀、覆盖索引、聚簇/二级索引 + 回表
2. 🔴 **事务 + 隔离级别**：ACID 靠什么保证、4×3 防脏读表格、幻读 vs 不可重复读

**怎么学**：B 站"MySQL 底层原理"（MySQL 45 讲视频版）+ 尚硅谷 MySQL 高级；本地装 MySQL 8.0 实际跑 `explain`、`show engine innodb status` 看锁。

## ⑥ JVM + Java 并发（大三上 · 面试必考深度）

### 档 2 · Java 并发（必会，另一大重点）

- 🔴 **CAS**：原理、ABA 问题怎么解决
- 🟡 ConcurrentHashMap 原理（接 ① 档 2）、AQS 是什么（Lock 的底层）、ThreadLocal（内存泄漏问题）、CompletableFuture（异步编程）

**怎么学**：B 站"JVM 内存模型""Java 并发编程" + 面试题背。**手写单例（双检锁 + volatile）必练**。ConcurrentHashMap / 线程池是高频题。

### 档 4 · 工程化层（⏱ 25-40h ｜ 📅 2027-06 投实习前 ｜ 🎯 挂在秒杀系统上）

- 🔴 **评测 Evals**：测试集 + LLM-as-judge + Bad Case 分析 ★差异化
- 🔴 **可靠性工程**：重试 / 超时 / **幂等** / 限流 / 降级 / 状态检查点 ← **你的强项直接迁移**
- 🟡 可观测性：Langfuse / LangSmith（Trace、Token 成本、延迟）
- 🟡 成本与延迟优化：**模型分层**（规划用大模型 / 执行用小模型）、KV Cache、批处理
- ⚪ LangGraph（Python）编排、多智能体模式、vLLM/Ollama 服务化

### 🔴 抗过时原则（比多学一个框架重要）

| 框架 API、模型名与价格、Agent 产品、具体 Prompt 技巧 | **RAG 检索工程**、上下文与记忆管理、工具调用与协议抽象、**可靠性工程**、成本-延迟-质量三角、并发/缓存/MQ/DB 基础 |
