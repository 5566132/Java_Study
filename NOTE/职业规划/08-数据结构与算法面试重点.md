## 一、先认清战场（为什么它和 ACM 不一样）

| 战场 | 考什么 | 难度 | 对应策略 |
|---|---|---|---|
| **笔试**（在线编程） | 模拟/贪心/二分/双指针/前缀和/DFS-BFS/树/图/DP/栈队列/链表 | LeetCode 中等~偏难 | 刷 hot 100 + 每周 Div2 |
| **面试手撕**（白板/编辑器） | 常见题，考熟练度+代码规范+复杂度 | LeetCode 中等 | 熟练 + 讲思路 |
| ACM 竞赛 | 难题构造/极限思维 | 远超面试 | ✅ 已退出，不再投入 |

**核心认知：ACM 能力是面试所需算法的超集，多出来的那截（难题构造、短时 AC 难题）对 Java 后端面试几乎零回报。你要保留的只是"能过笔试 + 能过手撕"这一层——每天 2h 刷题正好就是这一层。**

## 二、数据结构重点（面试常考，带"面试怎么问"）

### 🔴 必会
- **数组 / 字符串**：双指针、滑动窗口、前缀和、差分 —— *"最长无重复子串""和为K的子数组""接雨水"*
- **链表**：反转、快慢指针（环/中点）、合并有序链表、删除倒数第N个 —— *手撕最爱，画图讲清*
- **栈 / 队列**：单调栈（每日温度、接雨水）、栈模拟队列、括号匹配、最小栈
- **哈希表**：两数之和、统计频率、去重 —— *"空间换时间"的口头禅*
- **树（二叉树）**：前/中/后序 + 层序遍历、BST 性质、最近公共祖先、二叉树直径 —— *"先序中序能不能重建二叉树"*

### 🟡 加分
- **堆**：TopK（大/小顶堆）、合并 K 个有序链表、数据流中位数
- **图**：邻接表/矩阵、拓扑排序（课程表）、并查集（连通性）
- **字符串匹配**：KMP 了解（面试很少手撕，会讲原理即可）

### ⚪ 了解级（知道名词，别深钻）
- Trie（前缀树）、线段树/树状数组、跳表（Redis zset 会用到，可联动）

## 三、算法重点（按优先级排序，笔试题型 = 计划里的清单）

1. 🔴 **排序**：快排/归并/堆排，**能手撕前两个**；讲清稳定性和复杂度（快排不稳定 O(nlogn)，归并稳定）
2. 🔴 **二分**：标准写法 + 边界处理（开闭区间选一套用熟）
3. 🔴 **双指针 / 滑动窗口**：快慢指针、同向/反向、窗口收缩条件
4. 🔴 **前缀和 / 差分**：子数组和类题目（笔试高频）
5. 🔴 **DFS / BFS**：网格题（岛屿数量）、树/图遍历、visited 去重
6. 🔴 **回溯**：排列/组合/子集三件套模板（backtrack 三步：选→递归→撤销）
7. 🟡 **DP**：背包（01/完全）、最长递增子序列、编辑距离、打家劫舍系列；状压 DP 了解
8. 🟡 **贪心**：区间调度（无重叠区间）、跳跃游戏、分发糖果
9. 🟡 **单调栈/队列**：直方图最大矩形、滑动窗口最大值
10. ⚪ **图论进阶**：Dijkstra 最短路、最小生成树 —— 了解思路，中厂少见

**笔试重点题型（刻意练）**：模拟、贪心、二分、双指针、前缀和、DFS-BFS、树、图、动态规划、栈队列、链表 —— 这 11 类覆盖 90% 笔试题。

## 四、面试手撕的"隐形评分项"（很多人挂在这）

1. **先讲思路再写码**：30 秒说清"用什么数据结构 + 时间/空间复杂度"
2. **边界处理**：空输入、单元素、负数、大数、指针越界
3. **代码规范**：变量名有意义、不写拼音、循环不变量清晰
4. **写完走一个用例**：自己口头测一遍再提交
5. **被问"能不能优化"**：先答当前复杂度，再说空间换时间（哈希/前缀和）、双指针、排序预处理
6. **不会做也别慌**：说出暴力解法 + 瓶颈，再尝试优化——比憋着强

## 五、刷题路径（照着打勾）

```
第 1 阶段（前 4 周）：LeetCode hot 100 简单~中等，按题型刷（模拟/双指针/二分/前缀和），用 Java 写
第 2 阶段（大二结束前）：hot 100 全过 + hot 200 中等
第 3 阶段（大三上）：剑指 Offer + 高频题二刷
每周一场 CF Div2 只做 A/B（目标 CF 1600 ≈ 中厂笔试稳过线）
```

**规则**：卡 30 分钟没思路看题解，当天必须自己重新 AC；每道题记复杂度。
