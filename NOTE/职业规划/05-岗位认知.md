## 二、核心结论（背下来）

1. **Java 后端是双非求职的"就业面之王"**：岗位最多、门槛友好、薪资 1w+ 是基本盘。你的选择正确。
2. **C++ 不是没有岗位，是"少而精"+ 不写标题**：
   - 嵌入式/驱动岗大量要 C/C++，但标题是"嵌入式软件工程师""驱动开发"，**不带语言**——这就是你搜"C++"搜不到的原因
   - 游戏/音视频/基础架构也用 C++，但竞争激烈
3. **Python 的高薪岗（算法/AI）双非进不去**，排除正确。
4. **语言是可以互换的**：面试大头（网络/OS/数据库/并发/算法）和语言无关，岗位 JD 写"精通 Java/C++/Go 其一"很常见。

## 三、怎么搜岗位（实战技能）

**正确搜法**（BOSS直聘 / 牛客 / 实习僧）：
- 搜岗位名，不搜语言：`后端开发`、`软件开发工程师`、`Java 开发`、`应用软件工程师`、`嵌入式软件工程师`、`服务端开发`
- 加城市：`杭州 Java`、`深圳 后端`
- 小公司 JD 常见"精通 **C++/Java/Python 其一**"——投就完事，面试机会才是真的
- 用"筛选"功能按语言过滤（平台有"开发语言"筛选器，比关键词搜准）

**你主投的搜索词组合**：
```
Java 后端 / Java 开发 / 后端开发工程师
SpringBoot 项目加分：搜"Java 实习"（大二暑假）
```

**辅助投**（想用 C++ 时）：
```
嵌入式软件工程师 / 驱动开发 / 单片机软件 / 游戏服务端 / 音视频开发
```

## 五、岗位认知对简历的指导

- **简历技术栈按目标岗位写**：投 Java 后端就突出 Java/Spring/MySQL/Redis，不要写"精通 C++ 工程"（那是嵌入式岗看的东西）
- **投不同方向改一版简历**：主投 Java，辅投嵌入式/游戏时，把 C++ 项目（WebServer）放回显眼位置
- 你手里的牌：**算法笔试（ACM）** + **Java 项目** + **竞赛奖**——这张组合对中/小厂很有竞争力
