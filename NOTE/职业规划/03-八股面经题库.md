# 03 · 八股面经题库（Java 后端版）

> 八股 = 面试必问基础。**用法改了一下**：按"学习阶段"分组，**学完 [[01-技术栈学习路线]] 哪块，立刻做哪块对应的题**，不拖到大三。每题标 🔴必背 / 🟡加分。
> 标准：🔴 能 30 秒讲清楚（对着空气讲一遍），🟡 知道能聊几句。面试前每周过一遍。

## 整理方法

1. **随学随做**：学完 [[01-技术栈学习路线]] 某组，立刻做对应组题，把答案写成自己的 Q/A
2. **30 秒标准**：🔴 每题能 30 秒讲清楚（对着空气讲），讲不清就是没学会
3. **来源**：牛客面经、"JavaGuide"（`javaguide.cn`，Java 后端八股最全的免费站）、"面渣逆袭"（`javabetter.cn`，Java 后端八股免费站，与 README 第一行链接同源）、[[01-技术栈学习路线]] 里每块标 🔴 的知识点
4. **冲刺期**：大三上每周过一遍，大三下每天过
5. **不会的题先跳过**：标个问号，学完对应技术块再回来答，别卡住
