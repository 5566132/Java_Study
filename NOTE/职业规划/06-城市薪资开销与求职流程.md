## 一、先算账:你的存钱目标 = 需要什么档次的 offer

**你的目标**:正常开销(合租+吃饭+交通,不拮据)下,**每月净存 6-7k**。

(税前→到手按五险一金+个税约 15-22% 估算;开销按 2026 年"合租单间+正常吃饭"水平,会波动)

| 城市圈 | 税前月薪 | 到手 | 正常月开销 | **净存/月** | 达标? |
|---|---|---|---|---|---|
| 北京/上海 | 12k | ~9.6k | ~6.0k | ~3.6k | ✗ |
| 北京/上海 | 15k | ~11.8k | ~6.5k | ~5.3k | △ 勉强 |
| 北京/上海 | 18k | ~14.0k | ~6.5k | ~7.5k | ✓ |
| 深圳/杭州 | 12k | ~9.8k | ~5.2k | ~4.6k | △ |
| 深圳/杭州 | 15k | ~12.0k | ~5.5k | ~6.5k | ✓ |
| 成都/武汉/南京/苏州 | 9k | ~7.6k | ~3.8k | ~3.8k | ✗ |
| 成都/武汉/南京/苏州 | 13k | ~10.8k | ~4.2k | ~6.6k | ✓ |
| 郑州(二线) | 8k | ~6.8k | ~3.0k | ~3.8k | ✗ |

**核心结论**：
1. **目标存 6-7k ≈ 新一线税前 13k / 深圳杭州税前 15k / 北上税前 18k** → 对应的公司档次是**好中厂到大厂**
2. **性价比之王是杭州/深圳**：一线薪资 + 相对低开销,同样税前 15k 存得比北上多
3. **郑州基本存不到 6-7k**（岗位少 + 薪资低）,不做首选——这就是你必须去外面的原因
4. 你之前"稳拿 1w+"的念头可以往上提:**1w 在一线只够存 4k,要达成你的目标得奔着 13-15k+ 去**。计划的技术强度不变,目标公司档次往上调

## 二、求职流程:全程线上,只有入职才移动

**你以为的**:去一个陌生城市 → 在当地找房找工作。
**实际是**：你在河南,投的是**全国岗位**,流程全程线上：

```
投简历(BOSS/牛客/公司官网) → 线上笔试 → 线上视频一面/二面 → HR面 → 发offer → 入职那天才去那个城市
```

- **日常实习**：投递到 offer 约 2-4 周
- **暑期实习**：提前批 2 月投,3-5 月发 offer,7 月入职
- **秋招**：提前批 7 月,正式批 9-11 月
- 城市只影响你**入职后**的生活,完全不影响你**找工作**的过程

**一次性搬家成本**（不是每月负担）：
- 押一付三房租约 6k-1w + 路费几百到一千 + 第一个月生活费 1-2k
- 公司补偿：大厂/中厂多有**租房补贴或安家费**（每月 1-2k 或一次性 5k-1w）,部分提供第一年宿舍
- 暑期实习：很多公司报销路费、提供实习宿舍或补贴
- 结论：换城市总成本 ≈ 1w 以内,**第一月工资 + 补贴基本覆盖**,不必焦虑

## 三、城市推荐排序（综合存钱 + 岗位量 + 机会）

| 优先级 | 城市 | 理由 |
|---|---|---|
| 🥇 首选 | **杭州** | Java 岗多（阿里/网易/字节杭办）、薪资高、开销低于北上,存钱率最高 |
| 🥈 并列 | **深圳** | 互联网+硬件都强,Java 岗多,开销低于北上 |
| 🥉 次选 | 上海/北京 | 岗位最多、上限最高,但开销高,需 15-18k 才达标 |
| 4 | 成都/武汉/南京/苏州 | 性价比高,13k 就能存 6k+,适合求稳 |
| 5 | 郑州本地 | 只兜底,不做首选 |

**投递策略**：主投杭州/深圳/上海 → 辅投成都/武汉/南京 → 郑州垫底。多投几个城市,offer 来了再选,主动权在你。

## 四、公司补贴常识（谈薪资时心里有数）

- **五险一金**：一线大厂公积金比例高（12%）,变相相当于存钱（公积金账户是你的钱）
- **签字费/安家费**：大厂校招有,中厂部分有,几千到几万不等
- **年终奖**：多数公司 1-3 个月,看绩效
- **谈 offer 时问清楚**：公积金比例、年终奖几薪、有没有租房补贴——这些直接影响你到手和净存

## 五、一句话总结

> **你的存钱目标决定你要进"好中厂往上"的公司,城市选杭州/深圳/新一线。求职全程线上不用先搬家,换城市成本约 1w 且被补贴覆盖。别怕外面,怕的是不行动。**
