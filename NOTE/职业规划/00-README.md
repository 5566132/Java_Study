## 一、方向决定：为什么从 C++ 改成"Java 主投 + C++ 辅助"

你提出"C++ 岗位好像很少"——观察是对的，结论我已替你验证过（市场图景见 [[05-岗位认知]]）。修正后的方向：

**主语言学 Java，投 Java 后端岗；C++ 底子保留，作为竞赛奖、算法笔试和嵌入式第二出口。**

理由（每一条都对着你的目标"岗位多 + 1w+ 稳拿"）：

1. **岗位量 = 命中率。** Java 后端岗位数 ≈ 其他所有后端语言之和。双非学生，池子大 = 机会多，只要技术进池子前 20%，中厂 offer 不难。
2. **换语言成本远低于你的直觉。** 面试大头是 网络/OS/数据库/并发/算法，**这五块和语言无关**（约 80% 的面试内容），语言只占约 20%。ACM 出身学 Java 语法 1-2 周，真正要补的是 Spring 生态 + JVM 面试题。
3. **C++ 一点都不浪费。** 你的 ACM 底子体现为：**算法笔试几乎不挂**（双非简历筛选最怕笔试，你反而是优势）+ 竞赛奖写简历。想投嵌入式/游戏岗时 C++ 就是第二张牌。
4. **薪资逻辑说透**：不是"学得越多钱越多"，而是"学得越扎实 → 进的公司越好 → 钱越多"。Java 后端一二线应届 **1w+ 是基本盘**，好公司 15-20k。你的高强度换的是**进好公司的确定性**。
5. **城市不挑 = 直接瞄准薪资高地**（一线/新一线），薪资预期不设地域上限。

## 四、每天 6-8 小时怎么分

```
每天 2h   算法刷题   ← 笔试入场券，雷打不动（LeetCode 热题 100，**直接用 Java 刷**——练语法 + 笔试一举两得）
每天 4-6h 主线技术   ← 按阶段：Java8补漏 → MyBatis-Plus → SpringBoot → 苍穹外卖 → Redis/项目 → JVM
周末      6-8h 整块  ← 项目 + 写代码 demo
碎片时间              ← 看面经、写八股笔记、复盘、计网"遇到才学"反查
```

**作息现实（10 点起床、凌晨睡）**：你确认能保证**有效学习 6h+**，这就够了。别用"睡晚"惩罚自己——**按小时数打卡，不按几点睡**。"4-6h 主线"的标准是"学得进 4h"，不是坐满 6h 刷手机。困了就补觉，保证白天的 6h 是真的学。

**学习原则**（专治"会调用但不懂"）：
1. 每个知识点学完，**必须写一个能跑的 demo**，记"我做了什么/为什么"，不是"我看了什么"。
2. **能讲给别人听 = 学会了**（费曼）。
3. 所有项目 push 到 GitHub，简历放链接；技术博客从大二开始写。
4. **分层标记原则**：每块内容标 🔴必会 / 🟡加分 / ⚪了解（[[01-技术栈学习路线]] 起头有说明）。🔴 必须能讲透，🟡 面试加分按精力投入，⚪ 知道名词能聊几句即可——**别在 ⚪ 上花时间**，网上路线图的坑就是让人什么都想学。

**每学完一块就问自己三个问题**（对着 [[01-技术栈学习路线]] 的过关标准）：
- [ ] 这块的 🔴 我能不能不看笔记讲出来？
- [ ] 这块对应的高频面试题能不能 30 秒说清楚？（→ [[03-八股面经题库]] 打勾）
- [ ] 这块在我项目里用在哪？（没有就思考怎么用上）

## 五之二、AI / Agent 能力（2026-09 新增 · 后端增强线）

> **完整规划见 [[13-AI-Agent学习规划]]。** 这里只放结论。

**市场事实（2026 调研）**：
- 2026 年 1-7 月新发 AI 岗位同比 **+789%**，AI 应用开发占 AI 招聘 **61%**，Agent 开发需求 **+244%**
- 同时大厂在压缩传统后端岗 → **纯后端没消失，而是被改写成「Java 后端 + AI 集成能力」**
- **校招**口径：后端技术栈（Java/SpringBoot/MySQL/Redis/MQ）仍是**硬性**，AI 多为「**了解 + 有项目优先**」
- **社招**口径：AI 集成能力已变成硬性（Spring AI / LangChain4j 写进 JD）

**你的策略（关键：不改主线）**：

| 决定 | 内容 |
|---|---|
| 主线 | ✅ **仍是 Java 后端**，不动 |
| Agent 线 | 🟡 **穿插增强线**，每周 2-3h，不抢主线 |
| 语言 | Java 实现（Spring AI）；Python 只需"能读能改" |
| 预算 | DeepSeek + 百炼免费额度，**每月 50-100 元足够** |
| 做法 | ⭐ **不新建孤立 demo**，在每个项目里塞一个 agent 模块 |

**为什么这对你有利**：真正的 agent 工程难题是**状态持久化、幂等、重试、限流、成本控制、可观测性**——这些全是后端问题（云从科技「AI Agent 平台研发」JD 直接把「Runtime：分布式后端 / 状态持久化 / 长任务可靠性」列为方向之一）。**你的后端背景是地基，不是包袱。**

## 六、其他你该知道的事

- **旷课可以，绝不挂科**：尤其 C语言/数据结构/操作系统这些专业课，挂了对简历是硬伤。考试周突击过线就行。
- **绩点**：互联网开发岗不卡绩点，别内耗。但简历要交成绩单，别让挂科卡第一步。
- **内推是双非最大的杠杆**：加 ACM/技术社团群，找学长学姐内推，比海投有效 10 倍。
- **ACM 定位**（已定 2026-08-30）：**退出系统训练、不冲省金**（省铜已够证明"算法基础扎实"，升级边际价值小、成本大）。算法是硬短板（CF ~1200、Div2 只稳过 A/B），每天 2h 刷题当**刚需**补（**用 Java 刷** LeetCode 热题 100 → 热题 200 → 剑指 Offer，每周一场 Div2 只做 A/B，目标 CF 1600 过笔试）；省赛顺手报名当零成本彩票、不特训；**只退系统训练、不退圈子**——队里人脉保留，用于内推。**别吃 ACM 老本。**
- **英语**：能读英文文档（Spring 官方文档、技术博客）就够。
- **设计模式**：大三上花 1-2 周补高频几个（单例/工厂/策略/模板方法/代理/观察者），面试加分 + 拉开差距，Spring 底层全是它，见 [[01-技术栈学习路线]]⑩。
