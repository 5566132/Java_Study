## 一、分层体系（5 分钟建框架，别花多时间）

---

## 二、TCP 篇（面试最高频，重点中的重点）

### 🔴 必会
1. **三次握手**：流程（SYN→SYN+ACK→ACK）→ 为什么不是两次/四次（防失效旧连接、双方确认收发能力）→ 状态变化（SYN_SENT→ESTABLISHED）→ **SYN 泛洪**（半连接队列被打满）
2. **四次挥手**：为什么是四次（半关闭）→ **TIME_WAIT 为什么存在**（2MSL：保证对方收到 FIN + 让旧报文消失）→ 大量 TIME_WAIT 怎么办（端口复用/调短）
3. **可靠传输靠什么**：序列号/确认应答/超时重传/快速重传/滑动窗口
4. **流量控制 vs 拥塞控制**：流量控制 = 接收方窗口（点对点）；拥塞控制 = 网络状况（慢启动/拥塞避免/快重传/快恢复）
5. **TCP vs UDP**：连接/可靠/有序/开销/场景对比表

### 🟡 加分
- **粘包/拆包**：为什么（TCP 是字节流无边界）→ 解决（定长/分隔符/长度前缀）
- **TCP 保活机制**、半连接队列 vs 全连接队列（结合 SYN 泛洪）

---

## 三、UDP 篇

- 无连接/不可靠/无序/低开销/首部小
- 适用：视频流、语音、游戏、DNS
- **加分点**：HTTP/3（QUIC）就是基于 UDP + 自己实现可靠传输，解决 HTTP/2 队头阻塞

---

## 四、HTTP 篇

### 🔴 必会
1. **报文结构**（请求行/首部/空行/body）+ **状态码**：2xx(200)、3xx(301/302/304)、4xx(400/401/403/404)、5xx(500/502/503) 各举
2. **GET vs POST**：语义/参数位置/幂等/缓存（别背"GET 比 POST 安全"这种错话）
3. **无状态怎么保持**：Cookie / Session / Token 三选一的演进 + 分布式 session 问题
4. **HTTP/1.1 vs 2.0**：Keep-Alive、管线化、**队头阻塞**、多路复用、二进制分帧、头部压缩；**HTTP/2 还有没有队头阻塞（有，TCP 层的）**
5. **HTTPS 握手**：证书怎么防篡改（CA 数字签名）→ 非对称换对称密钥 → 加密通信（TLS1.2/1.3 简单讲）

### 🟡 加分
- HTTP/3 QUIC（一句话）、Cookie 属性（HttpOnly/Secure/SameSite）

## 五、必背综合大题（一字不差背熟）

### 🔴 "浏览器输入 URL 到页面显示，发生了什么"
```
1. DNS 解析域名 → IP（缓存：浏览器→系统→路由器→DNS服务器）
2. TCP 三次握手建立连接
3. 客户端发 HTTP 请求（GET /...）
4. 服务器处理，返回 HTTP 响应
5. 浏览器解析 HTML/CSS/JS，构建 DOM 树 → 渲染
6. 四次挥手断开（或 HTTP/1.1 长连接复用）
```
> 面试官会从这里往任意方向深挖（DNS/TCP/HTTP/渲染），这题是"开卷的口子"。
