## 一、简历（从大二暑假开始迭代，不是大三才写）

**结构（一页）**：
```
教育背景：学校 + 专业 + 毕业时间 + 竞赛奖项（ICPC/CCPC 省铜）
项目经历：2 个（STAR + 数据）        ← 占 50% 篇幅
技术栈：Java / SpringBoot / MySQL / Redis / 网络
其他：GitHub + 技术博客 + 英语水平
```

**竞赛奖写法**（你的省铜不是废的）：
- ✅ "XX届 ICPC 省赛铜奖（算法设计与实现，C++）"——**定位成"算法基础扎实"的证据**
- 它的价值：让 HR 相信你**能过算法笔试**，这关很多双非学生挂在这里

**STAR 写法**：背景→任务→行动→结果（带数据）。参考 [[02-项目规划]] 模板。

## 二、实习链（双非的生命线）

**没有实习，双非简历大概率简历关就沉底。** 三段式：

| 阶段 | 时间 | 目标 | 投什么 |
|---|---|---|---|
| **日常实习** | 2027 大二暑假 | 第一段实习，**不挑公司**，小厂也行 | BOSS直聘/实习僧/牛客 |
| **暑期实习** ⭐ | 2028 大三下（提前批 2 月就开） | 最关键一战：拿到=转正机会+秋招跳板 | 目标公司提前批+正式批全投 |
| **秋招** | 2028 大四上（提前批7月，正式9月） | 大厂冲刺 + 中厂保底（各 10 家） | 全渠道 + 内推 |

**日常实习怎么找（大二暑假）**：
- 广撒网：小公司、创业公司、学长公司都投，**先有"实习"两个字**
- 远程实习/外包也考虑（第一段经历的含金量 > 公司大小）
- 技能提示：大二暑假就有 SpringBoot + 秒杀项目 + 基础算法，足够面试小公司

**城市策略（结合存钱率算的，账见 [[06-城市薪资开销与求职流程]]）**：
- **首选 杭州 / 深圳**：一线薪资 + 相对低开销，同样税前 15k 存得比北上多，存钱率最高
- **次选 上海 / 北京**：岗位最多、上限最高，但开销高，需税前 15-18k 才达成存钱目标
- **新一线（成都/武汉/南京/苏州）**：性价比高，税前 13k 就能存 6k+
- **郑州只兜底不做首选**——目标每月存 6-7k，本地存不到
- 投递顺序：杭州/深圳/上海 → 新一线 → 郑州垫底，多投几个城市，offer 来了再选

## 三、双非补短板的具体动作（性价比排序）

1. **技术博客**（最值钱）：大二开始写，项目复盘 + Java 知识点。写够 10 篇，简历放链接。
2. **GitHub**：项目 + demo 持续 push（HR 会看活跃度）。
3. **内推**：加 ACM/技术社团群、找学长学姐。**双非最有效路径是内推，不是海投**。
4. **实习经历**：见上。
5. **算法笔试能力**（⚠️ 硬短板）：真实水平 CF ~1200、Div2 只稳过 A/B，中厂/大厂笔试会挂。**每天 2h 刚性刷题**（LeetCode 热题 100 + 每周一场 Div2，先稳定过 AB），目标 1600。**别吃 ACM 老本**——这块不补，双非简历会沉在笔试关。

## 四、时间线里的求职动作

| 时间 | 求职动作 |
|---|---|
| 2026 大二上 | 开始写博客第 1-2 篇；加技术社团/学长群 |
| 2026 大二上末 | 苍穹外卖跑通（练手，**先不上简历**）；期末把项目代码 push GitHub |

| 2028 大三暑假 | 暑期实习；7-8 月投秋招提前批 |
| 2028 大四上 | 9 月秋招正式批：大厂 10 + 中厂 10 + 内推为主 |

## 五、薪资现实锚点（别被忽悠也别自我设限）

| 城市圈 | Java 后端应届月薪 | 说明 |
|---|---|---|
| 一线（北上广深杭） | 12-20k | **主攻目标**，1w+ 是基本盘 |
| 新一线 | 9-15k | 性价比高，够 1w+ |
| 二线/郑州 | 7-12k | 兜底，一般不做首选 |

- 决定薪资的不是"学了多久"，是**公司档次**：大厂/好中厂 15k+，普通小厂 8-12k
- 想冲 15k+ = 王牌实习 + 项目出彩 + 八股过硬，正好是你的计划目标
- **你的目标不是"1w+"，是"净存 6-7k"**：一线税前 1w 只够存 4k，达标需新一线税前 13k / 杭州深圳税前 15k+（完整测算见 [[06-城市薪资开销与求职流程]]）

## 六、如果时间紧，砍什么（优先级从高到低）

```
① 黑马点评/秒杀（简历主项目）  ← 不能砍，简历命根
② 计算机网络                  ← 不能砍，必考（⚠️ 你现在还是空的）
③ SpringBoot/Java             ← 不能砍，Java 岗核心
④ 八股整理                    ← 可压到冲刺期集中搞
⑤ MySQL/Redis                 ← 后学，但面试占比 20%
⑥ 项目3（RPC/MQ）             ← 简历项目做完后优先级上升
⑦ 苍穹外卖                    ← 练手用，做完即走，别恋战
⑧ 技术博客                    ← 有剩余精力再写（性价比高）
算法刷题                      ← 每天 2h 不砍（⚠️ CF 1200 是硬短板）
```

## 七、心理建设（写给迷茫的你）

- 你才大一暑假，现在开始 = 比 90% 的大二学生早。**时间是你最大的优势。**
- 你的三个选择（Java 主投、C++ 辅助、城市不挑）已经把"岗位少"的风险化解了，剩下的就是执行。
- **别跟别人比进度，跟自己的计划比。** 迷茫的解药是"今天该学的学完了"。
- 绩点不好不致命，但**别挂科**。
- 每周看完这篇 + [[00-README]] 一次，确认自己在时间线上。
