# 10 · 操作系统面试重点（权重 ~15%）

> 通用基础，和网络并列为"基础四大件"，面试必考但深度可控。

## 一、进程与线程（最高频）

### 🔴 必会
1. **进程 vs 线程**：资源分配/调度/开销/通信/崩溃隔离
   - 一句话：进程是资源分配单位，线程是 CPU 调度单位；进程有独立地址空间，线程共享
2. **进程状态 + 切换**：就绪/运行/阻塞；上下文切换为什么贵（保存/恢复寄存器+内核态切换）
3. **进程调度算法**：FCFS、SJF、时间片轮转、优先级、多级反馈队列 —— *"各适合什么场景"*
4. **进程间通信（IPC）**：管道、消息队列、共享内存、信号量、信号、Socket —— *"共享内存为什么最快（零拷贝用户态）"*

### 🟡 加分
- **协程**：用户态线程，切换更轻（Java 虚拟线程/Kotlin 协程可联动聊）

---

## 二、同步与死锁

### 🔴 必会
1. **并发三大问题**：互斥、死锁、饥饿
2. **信号量 / PV 操作**、管程（Moniter：Java synchronized 底层就是管程思想）
3. **死锁四条件**：互斥、持有并等待、不可剥夺、循环等待 —— 必背
4. **死锁处理**：预防（破坏四条件）、避免（银行家算法）、检测与解除；*"MySQL 死锁怎么排查"联动 [[11-数据库面试重点]]*

### 🟡 加分
- 自旋锁 vs 阻塞锁（自旋适合短临界区）、活锁

---

## 三、内存管理（面试必考）

### 🔴 必会
1. **虚拟内存为什么存在**：隔离（进程互不干扰）+ 扩展（比物理内存大）+ 简化管理
2. **分页 + 页表**：逻辑地址→物理地址映射、多级页表
3. **缺页中断**：访问不在内存的页 → 调页 → 页面置换
4. **页面置换算法**：FIFO、LRU、LFU（+ Belady 异常：FIFO 页框变多缺页反而变多）
5. **分页 vs 分段**：分页无外部碎片、分段有逻辑意义

### 🟡 加分
- **局部性原理**（时间/空间）→ 缓存/TLB 的设计依据
- 内存映射 mmap（和零拷贝联动）

---

## 四、其他高频

### 🔴 必会
1. **用户态 / 内核态**：为什么分（安全隔离）、系统调用、切换开销
2. **select / poll / epoll**（**加分大项**，和网络/Redis 联动）：
   - select：fd 数组、有上限 1024、每次都要把 fd 从用户态拷内核态、线性扫描
   - poll：链表、无上限，其他同 select
   - epoll：红黑树 + 就绪链表、回调机制、**无需每次全量拷贝/扫描**，水平/边沿触发
   - *"Redis 为什么用 epoll"——面试官最爱*
3. **IO 多路复用**是什么、阻塞 vs 非阻塞 vs 异步

### 🟡 加分
- **零拷贝**（sendfile：内核态直接搬，减少两次拷贝）—— 知道概念能聊即可

### ⚪ 了解级（面试考得少，别花时间）
- 计算机组成原理：冯·诺依曼结构、CPU 缓存/总线、局部性 —— 有空再看
