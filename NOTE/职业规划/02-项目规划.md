## 项目0：苍穹外卖（练手过渡 · 大二上末起）

**定位说清楚**：它的价值**不是简历，是"从会语法到会写业务代码"的桥**。做完它你才知道 Controller/Service/Mapper 怎么串、JWT 怎么鉴权、Redis 怎么塞进业务里。**该踩的坑照踩，那才是真收获。**

**技术栈**：SpringBoot + **MyBatis-Plus** + Redis + JWT + Nginx + 微信小程序 + WebSocket + EasyExcel

**要练到的点**（每个都能讲 3 分钟才算过）：
- 三层架构怎么流转 + RESTful 接口设计
- JWT 双端登录鉴权 + 拦截器 + 全局异常处理
- MyBatis-Plus 的分页 / 条件构造器 / 逻辑删除 / 自动填充（**替代 PageHelper**）
- Redis 缓存菜品 + **缓存一致性**问题
- WebSocket 来单提醒（长连接 vs 轮询）
- 微信支付流程：下单 → 回调验签 → 改订单状态
- EasyExcel 导出运营报表
- 跨域、缓存不一致、JWT 失效 —— **踩过的坑要记录下来**

**完成标准**：
- [ ] 独立完成 1 个完整业务模块（推荐菜品管理，**不看视频重写**）
- [ ] 整体跑起来，能讲清三层架构怎么流转
- [ ] 能说出 ≥3 个自己踩的坑 + 解决方式

**AI 模块：智能客服（Function Calling）** ← 详见 [[13-AI-Agent学习规划]] 第二节"专项评估"

> **定位**：这是 **Function Calling 练习，不是 Agent**。面试就按这个说，别夸大成"我做了个 agent"。
> **时机**：**必须在订单模块做完之后**（要先有订单才查得出来），且**先做一个 20 分钟热身**——写一个 `@Tool` 方法返回假数字，先跑通"模型调用我的代码"这条链路。

| 步骤 | 做什么 | 耗时 |
|---|---|---|
| 热身 | `@Tool` 方法 `queryTodayOrderCount()` 返回假数字，让模型回答"今天多少单" | 20 分钟 |
| 正式 | `@Tool` 暴露 2-3 个**只读**查询方法（查订单数 / 查热销菜品），模型调真实 Service | 15-20 小时 |

**🔴 三条硬约束（不遵守会出事）**：
1. **只暴露只读方法**，方法名带 `query`/`get` 前缀——绝不暴露 `deleteOrder` 这类写操作
2. **方法内部必须校验参数**——模型生成的参数不可信，绝不拼接 SQL
3. **必须加限流 + 控制台设消费限额**——用你在秒杀项目学的令牌桶，直接迁移

**📖 面试话术**（比"我做了多智能体"加分得多）：
> "我做了 Function Calling 的落地，并且评估后**故意没上 agent**——单轮查询已满足需求，上 agent 会引入不确定性、更难调试、还更贵。"

**成本**：开发期间 API 花费约 **1-2 元**（每次问答约 500-2000 token）。

**若要上简历，必须二开**（否则不加分反而暴露"只会跟教程"）：
1. 升级 **JDK 17 + SpringBoot 3**，亲手趟 `javax` → `jakarta` 迁移
2. 修原作者留的 bug
3. 把 Redis 部分讲深（缓存一致性 / 分布式锁 / 穿透击穿雪崩）
4. README 写：架构图 + 你的改造点 + 难点 + 怎么跑

> ⚠️ **判断标准**："跟着敲完" ≠ "项目"。不看视频能重写 + 能连续讲 30 分钟 + 能回答追问，才算。

## 项目1：黑马点评（大二下 · 简历主项目 · Redis 面试全在这）

**为什么必须有它**：面试官问 Redis 只问**穿透/击穿/雪崩、分布式锁、缓存一致性**，不问你怎么用。苍穹外卖的 Redis 太浅，**黑马点评正好把这些全讲透**，性价比比外卖高得多。

**核心模块和技术点**：
- **缓存三大问题**：穿透（布隆过滤器/空值缓存）、击穿（互斥锁/逻辑过期）、雪崩（过期时间错开/多级缓存）
- **分布式锁**：SetNX + 过期时间 + 续期 → Redisson 看门狗原理
- **秒杀券**：Redis 预减库存 + 一人一单（乐观锁）
- **缓存一致性**：先删缓存还是先更新 DB、延迟双删
- Redis 实战数据结构：ZSet 点赞/排行、Stream 异步队列

**完成标准**：
- [ ] 秒杀券功能**独立实现**（不照抄），能讲清分布式锁原理
- [ ] 能分别讲清穿透/击穿/雪崩的解决方案（含布隆过滤器原理）

## 项目2：Java 秒杀系统（大二下完成，简历主项目）

**为什么是秒杀**：这是 Java 后端**最经典**的高并发业务项目，教程最多，面试话题最丰富（Redis 缓存 + 消息队列削峰 + 分布式锁 + 限流 + 超卖问题），一箭多雕。

**做什么**：一个商品秒杀系统——用户抢购，要求高并发下不超卖、不卡死。

**核心模块和技术点**（每个都要能讲 3 分钟）：
- **登录/鉴权**：Session / Token（JWT）
- **持久层**：**MyBatis-Plus**（CRUD + 条件构造器 + 逻辑删除，替代手写 XML）
- **Redis 预减库存 + 缓存**：把库存放 Redis，抗住高并发读
- **消息队列削峰**：RabbitMQ / RocketMQ 异步下单（可选，用 RabbitMQ 入门）
- **分布式锁**：Redis setnx 实现，防超卖
- **接口限流 + 防刷**：令牌桶 / Redis 计数
- **数据库**：MySQL 事务 + 乐观锁/悲观锁兜底
- **超卖问题的完整回答**（面试高频）：预减库存 → 队列 → 落库

**怎么做**：
- B 站搜"秒杀系统"（黑马/尚硅谷都有完整教程），**跟着做 + 自己改造加亮点**
- 亮点方向：压测对比（Jmeter/ab 测 QPS）、缓存一致性方案（Cache Aside）、引入分布式锁对比
- README 必须有：架构图 + 亮点 + 压测数据 + 怎么跑
- 全部代码 push GitHub

**完成标准**：
- [ ] 能跑，压测有数据（对比"有缓存/无缓存"QPS）
- [ ] 能在面试**连续讲 30 分钟**（从架构到每个技术点）
- [ ] 能完整讲清"秒杀为什么不超卖"

## 项目3：更显深度的项目（大三上，三选一）

目的：体现"我不只会调框架，还懂底层"。这是和中厂/大厂 Java 岗拉开差距的关键。

**候选 A：简易 RPC 框架（Java）**
- 动态代理 + 序列化 + 网络传输 + 注册中心（了解）
- 最能体现深度，基础架构方向面试官喜欢

**候选 B：简易 KV 存储 / Redis 复刻**
- 内存存储 + 持久化 + 过期机制 + 网络协议
- 学完 Redis 后做，知识点闭环，面试话题多

**候选 C：简易消息队列**
- 生产者-消费者 + 网络 + 持久化 + 主题分区
- 分布式方向友好

**选择建议**：主线 Java 后端 → 推荐 **A（RPC）** 或 **C（MQ）**；若想兼顾"懂数据库"→ B。

## 项目通用原则

1. **一个项目 = 一个主线 + 1-2 个亮点**，不堆砌功能
2. README：架构图 + 亮点 + 难点 + 压测数据 + 怎么跑
3. 面试必答题准备：
   - 为什么这么设计？（有哪些方案，为什么选这个）
   - 并发上不去怎么办？（瓶颈在哪）
   - 超卖/缓存不一致/宕机了怎么办？
4. **写博客复盘每个项目**（双非简历性价比最高的加分项）
5. **前端只做门面**：项目前端用现成模板（LayUI / AdminLTE / 若依）或极简页面即可，**不投入时间学前端**（对齐二哥路线：界面丑点无所谓，重点在 Java 后端）

**模板四 · 加了 AI 模块之后的写法（⭐ 目标形态）**

```
**高并发秒杀系统 + AI 成本治理**（SpringBoot + MyBatis-Plus + Redis + Spring AI）｜ 2027.06
- 基于 Redis 预减库存 + 消息队列异步下单，压测 QPS 从 X 提升至 Y
- 设计 LLM 网关层：令牌桶限流 + 失败重试幂等 + 降级兜底，保障大模型调用不拖垮主链路
- 落地模型分层策略（规划用大模型 / 执行用小模型）+ 语义缓存，Token 成本降低约 X%
- 接入 Langfuse 全链路 Trace，建立 Token 成本与响应延迟看板
```

```
**点评平台 + RAG 智能问答**（SpringBoot + Redis + Spring AI + pgvector）｜ 2027.05
- 基于 pgvector 构建商户知识库，文档分块 + 混合检索（BM25 + 向量 + RRF）提升召回率
- 用 Redis 实现语义缓存，相似问题命中率 X%，平均响应从 X ms 降至 Y ms
```

## 项目资源库：从"只会黑马练习"到"几个像样的项目"

> 📌 进度台账见 `SpringBoot_Note/进度追踪.md`。当前正处于 **① 苍穹外卖前的准备阶段**（MyBatis-Plus → SpringBoot）。

你现在只有 C++ 控制台小练习和一个线程池——**那些是"练习"，不是"项目"**。别慌，按这个路径走，资源全是现成的：

**① 过渡练习（大二上 · 正在进行）**
- **苍穹外卖**（黑马官方）：SpringBoot + MyBatis-Plus + Redis 全家桶，几十个接口。这是你当前的主线，练 Web/持久层的实战手感
- 作用：把"会用语法"变成"能搭 CRUD 业务接口"，给后面的项目打底

**② 简历主项目一：黑马点评（大二下，Redis 深挖）**
- 技术栈：SpringBoot + Redis + Redisson + Lua
- 做法：跟完后**秒杀券功能自己重写一遍**，能讲清分布式锁原理
- 这是**面试官问 Redis 时的弹药库**，优先级高于苍穹外卖

**③ 简历主项目二：秒杀系统（大二下，跟着做 + 改造）**
- 教程：B 站搜"秒杀系统"，**黑马 / 尚硅谷 / 诸葛** 都有完整版（SpringBoot + Redis + MQ 全家桶）
- 做法：先 1 倍速跟完 → 自己重写一遍（不看视频）→ 加 2 个亮点（见上"怎么做"）
- **跟做 ≠ 项目**，重写 + 能讲才是

**④ 深度项目：三选一（大三上）**
- RPC 框架：B 站"手写 RPC 框架"（搜"Java 手写 RPC"有完整系列）
- 简易 Redis / KV：学完 Redis 后，参考 GitHub 开源 MiniRedis
- 简易 MQ：B 站"手写消息队列"
- 挑一个跟完，你的深度就拉开培训班学生了

**⑤ 项目资源平台（长期用）**
- **牛客项目专栏**（牛客网 → 项目），Java 后端项目多且能投递练习
- **GitHub**：搜 `springboot seckill` / `rpc framework` / `mini redis` / `sky-take-out`，看成熟项目的结构（分层/异常/规范）
- **JavaGuide**（javaguide.cn）：有"项目实战"专题 + 面试追问合集
- **技术社区**：掘金/知乎搜"Java 后端项目"教程合集，很多带源码和笔记
- **苍穹外卖二开参考**：[从"苍穹外卖"到"敕勒食驿"：项目升级实战](https://segmentfault.com/a/1190000047619546)

**⑥ 项目驱动学习法（专治"知识不知道用在哪"）**
> 学每个技术点，都问一句"它在我项目里用在哪"：
> - 学 Redis → "秒杀库存放这"；学 MQ → "下单削峰用这"；学分布式锁 → "防超卖用这"
> - 先学能做的项目，再学项目要用的技术——**技术永远围着项目转**
