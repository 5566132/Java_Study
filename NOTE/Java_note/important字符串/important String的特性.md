String是一个类, 一个非常重要的特性是字符串(String)不可被改变,
在java里面, 一个字符串类被创造的那一刻就永远是以这个样子存放在堆里面, 对这个字符串的一些操作都是创造了一个新的字符串,永远不是对原先字符串的操作
比如replace操作就是创造了一个新的字符串, 但是原来那个依旧被保留了

这个特性延伸出一些问题, 比如, 你的每次操作都会导致出现一个新的字符串, 导致内存占用比较大, 速度较慢等等, 一会儿说StringBuilder类可以解决

当然String身为一个类, 当然是引用数据类型
虽然可以String s1 = "abcd"这样创建, 但是依旧是引用数据类型(这样创建的话字符串是存在于字符串池里面, 这个东西也是在堆里面的)


准确的说对于包装类 String Integer 等, 使用 赋值= 操作本质是new这个操作,
String s = "abc";
s = "666";
本质是, new了一个新的String对象, 让s的存的地址变成这个新对象的, 值自然也是新的了
