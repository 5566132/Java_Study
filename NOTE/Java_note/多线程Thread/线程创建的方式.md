直接用线程类创建线程(这个比较占用资源, 项目应该是不用的, 但是这个是属于底层)
Thread t1 = new Thread();
t1.start()
创建一个线程, Thread类内部有一个run()方法相当于线程的执行方法, 使用start()方法会执行这个run, 所以其他类继承Thread要重写run(), 目的就是让run()的内容是我想要的


## 类实现Runnable类
实现了Runnable的类需要重写run()方法, 这个类的对象可以传递给线程, 之后starrt就是执行Runnable类的对象
MyThread mt = new MyThread();
Thread t1 = new Thread(mt);
t1.start();
Runnable解决了一个类想要变成线程必须继承Thread的问题, 现在类可以去实现Runnable接口去作为一个线程使用

## 实现Callable<>接口, 以及利用FutureTask类
这个跟Runnable差不多, 只是多了一个可以接收返回值的功能
假设类MT实现了Callable接口, 那就要重写call方法 -> 这个方法跟run功能一样, 线程调用的时候就直接调用这个call了, 但是call可以有返回值, 继承Callable<>接口的泛型就是返回值类型
MT mt1 = new MT();  -> 创建实现了Callable接口的对象
FutureTask\<Integer> f1 = new Future<>( mt1 ); -> 创建对象接收mt1的返回值
Thread t1 = new Thread(f1); -> 创建线程
t1.start(); -> 执行线程
f1.get(); -> 得到返回值


综上, 这三种线程的创建方式本质都是需要Thread作为底层才能真正执行线程
Runnable 和 Callable\<> 被称为任务, 是需要传递给线程才能被执行的, 而Future的功能就是接收任务的返回值, 以及控制任务
