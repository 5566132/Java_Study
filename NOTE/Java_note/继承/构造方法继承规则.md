先说一下this()和super()在这里的用处
如果你的语句只写一个this();  JVM会直接调用当前类的无参构造
当你的子类构造方法里面没写this();   JVM就会默认给你添加super();   
你也可以手动添加super();然后把参数写里面, 但是这个语句必须在构造的第一行
形式如下
public class father{
	public String name;
	public int age;
	father(){
		name = "";
		age = 0;
	}
	father(String name, int age){
		this.name = name;
		this.age = age;
	}
}

public class son extends father{
	public int salary;
	son(){
		this(null, 0, 0);
		//super();
		this.salary = salary;
	}
	son(String name, int age, int salary){
		super(name, age);
		this.salary = salary;
	}
}
看这个子类的构造的第一行都有一个super();这个是我手动加上的, 但是如果不手动加上JVM也会自动加上, 但是只加上父类的无参构造, 也就是super();
当然, 在无参构造里面也可以写this(参数);去调用有参构造, 给变量赋值
