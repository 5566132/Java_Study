黑马说只有能写在虚方法表里面的方法可以被重写

方法继承 用虚方法表, 也会直接继承, 比如final方法就要
方法继承的时候会创建一个**虚方法表**
这个东西大概就是类似指针的结构, 你想调用哪个方法的时候能快速访问到这个方法, 不至于向上访问1000个父类才找到这个方法

**虚方法表**
只存 非private 非static 非final 的方法
每次继承都会把本类需要加入的方法加入, 然后把这个表向下继承, 
覆盖规则就是, 本类重写了父类的同名方法就会把表里面的(那个类似指针的结构给改变指向)覆盖, 用最新的这个

对了, 重写方法的时候在这个方法的上一行加上个关键字@Override
