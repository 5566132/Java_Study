java就两种数据类型, 一个是基本数据类型, 一个是引用数据类型
基本数据类型基本就是int , double ,  char这类的
引用数据类型就是其他的所有的东西
引用数据类型特别类似指针, 其本身存的是地址, 地址里面存的才是值
你一般new出来的, 或者所有的类都是引用数据类型
比如你的int`[]`需要new出来吧, 那这个就是引用数据类型
还有String它本身是个类, 所以, 也是引用数据类型
那既然是地址就注定了一件事, 就是不能用 == 去比较两个引用数据类型是否相等, 因为这个时候比较的永远是地址

**我觉得你在写代码的时候要时刻想到类的实例都是引用数据类型, 进而考虑自己的一些操作是否是合理的**

**哈哈哈哈哈, 我又发现一个重点, 就是引用数据类型只代表这个变量本身是个地址, 通过这个地址才能访问内容, 不意味着递归的时候对这个变量的修改可以传递到每个递归上, 也就是说这个变量并非全局通用的, 只是当前递归内部通用而已, 当前递归对其的修改不会影响到更上层的递归**
