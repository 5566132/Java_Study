监听就是给某些类添加一个被叫做监听的接口, 然后就能通过这些类就能监听到鼠标或者键盘的一些行为
三种监听模式
动作监听ActionListener
只能监听到鼠标左键和空格键
鼠标监听MouseListener
鼠标划入, 鼠标划出, 鼠标按下, 鼠标松开, 鼠标点击 一共五种监听事物
键盘监听KeyListener
键盘按下, 键盘松开, 还有一个Typed

这三种监听都属于接口, 所以使用的时候要去重写里面的方法
可以回忆一下匿名内部类的写法, 用这个形式重写接口也是可以的
当然, 也可以直接实现接口, 然后在类内部重写方法

ActionListener有一个方法
@Override
public void actionPerformed(ActionEvent e){
	
}

MouseListener有5个
mouseClicked(MouseEvent e){};
mousePressed(MouseEvent e){};
mouseReleased(MouseEvent e){};
mouseEntered(MouseEvent e){};检查是否划入指定区域
mouseExited(MouseEvent e){};


KeyListener有3个
keyTyped(KeyEvent e){};
keyPressed(KeyEvent e){};
keyReleased(KeyEvent e){};

这些监听都需要结合一些组件去使用, 比如把鼠标监听绑定按钮jbt.addMouseListener(this) -> 这里面写this的写法只能当前类实现了MouseListener接口且类内重写了方法的时候可以用
否则就需要用
jbt.addMouseListener(
	new MouseListener(){
		重写接口方法
	}
)
这是匿名内部类的写法,这样才能用
总之参数部分要传递接口(MouseListener类型)的对象

把内容面板绑定键盘监听也是这个写法
this.getContentPane().addKeyListener(this);
