this.setSize(x,y);设置界面的长和宽
这里有个细节, JFrame的框架规定左上角是(0 , 0)   向右延伸是x轴
向下延伸是y轴, 记住了, 有的方法需要利用x y设置, 所以要严格遵守这个规则,
不然就会出错

this.setTitle(字符串);给界面添加标题

this.setAlwaysOnTop(true);规范界面永远被系统聚焦

this.setDefaultCloseOperation(可以写0, 1, 2, 3);
设置界面与进程的联动关系, 系统定义了4个final变量, 他们的值分别是这四个数, 其中3代表所有 JFrame 界面都关闭才会终止进程

this.setLayout(null);
设置组件的布置模式, null才能随意布置组件, 否则只能按照系统默认的方式放置

延伸一下, 说一下 JFrame 界面和组件
组件这个东西包括菜单栏, 按钮, 监听啥的东西, 这些东西都是要在构建完成之后添加到界面才能生效的东西, 界面本身就是一个空白区域而已
而一般组件都是先给组件构造好, 然后把它添加到 JFrame 比如JFrame可以添加菜单栏, 但是菜单栏里面的内容你要针对菜单添加, 比如要在菜单栏里面添加菜单而非把菜单添加到 JFrame
