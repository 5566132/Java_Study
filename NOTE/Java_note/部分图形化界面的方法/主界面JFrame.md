想要一个图形化界面就必须有个主界面, 也就是这个JFrame, 这个主界面的一大作用是,其他所有组件以及其他功能都要依托于这个界面才能生效
主界面的具体创建方法就是
先将你的类继承 JFrame 这个类, 然后就能写一些方法在方法里面new这个主界面类
JFrame jf = new JFrame();
当然, 这个不是主流做法, 因为你继承的父类JFrame里面是存在一个主界面的, 也就是没必要在子类里面再创建一个主界面, 
而这个隐藏主界面的访问方法就是 this.getContentPane();  this是指本类对象,这个整体其实就是一个JFrame类型的对象, 所以, 其他操作就都在这个基础上进行就行

**important**
如果你创建了一个类然后继承了JFrame这个类, 那么你这个类会默认有一个JFrame类型的主界面, 这个东西是JFrame的默认构造自动创建的, 因此你的this调用的方法都是针对这个本类的主界面实施的方法, 自然就会作用在本类的这个JFrame上面

**Very Important**
主界面分为一个主界面和一个内容面板
菜单栏是添加到内容面板里面的, 组件是添加到内容面板里面的
this.getContentPane()是得到内容面板这跟JFrame不是一个东西
