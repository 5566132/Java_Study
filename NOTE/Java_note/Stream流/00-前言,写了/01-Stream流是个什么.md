1.首先知道这个东西基本就是针对数组/集合使用的, 也就是这类东西可以创建流, 同时更常用
2.流就是把集合转成Stream\<String> 类的对象, 然后可以用相关的方法操作这个对象
3.这个的作用主要是简化操作, 代码书写方便

### 原理
流底层使用的就是迭代器, 但是还会封装一些其他东西去辅助记录, 
比如跳过前几个需要用个count记录, 
distinct底层先遍历一遍集合, 然后用HashSet记录重复元素, 将这个HashSet传递给下一个流
那这么说, **其实除了终结方法, 其他的方法都是懒标记,  只有等到终结方法的时候才会让这些标记起作用**, 就像filter我只需要标记"我需要用这个方法过滤元素"等到终结方法的时候再真的过滤即可,
