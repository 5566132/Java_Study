这就是一个数组操作类, 操作各种类型的数组   类`[]` 这个整体叫数组
操作的时候只能操作同类型的 类数组

Arrays里面的方法差不多都是static的, 也就是说, 都要用类名加方法名调用

**Arrays对包装类, 和自己创建的类的操作不太一样, 注意这一点**

Arrays.copy(数组名, 复制的长度);
这个什么长度都能复制, 不足就只复制前几个, 超出则会有默认值填充
对于包装类, 这个是深拷贝, 自创类则是浅拷贝

**Arrays.sort(数组名, 规则);**
这个规则的位置是一个接口类型的变量, 这也就说明, 这个位置需要接收一个
Comparator接口的实现类对象, 用匿名内部类或者Lambda都行, 但是要注意这个接口
有泛型要求, 也就是匿名内部类写的时候要指定好类型
