首先要知道这两个都是接口, 而且都是泛型接口

imp:
这两个比较器的规则都是返回 正数代表调用者更大(第一个参数)  0代表二者相等
负数代表调用者更小


一般这个接口是作为类的实现接口的, 也就是把重写方法写在类内部
Comparable\<E>这个接口里面有一个抽象方法
public int compareTo( E e ){
	return int
}
只有一个形参, 

Comparator\<E>
这个接口则是作为sort, TreeMap之类的东西的规则, 充当一个比较器
比如TreeMap
TreeMap\<Stu, Integer> m = new TreeMap( new Comparator\<Stu>(){
	@Override
	public int compare( Stu a , Stu b ){
		return a.age - b.age;
	}
});
采用匿名内部类的形式去重写方法, 然后按照规则排序, 去重
