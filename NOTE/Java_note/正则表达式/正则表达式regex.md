这个东西就是用一些特定的符号去充当类似通配符的东西, 然后去匹配文本内容
比如,一个手机号固定是第一位是1,其他位可以随意, 然后给你一个大文本, 问里面都有哪些手机号, 你可以封装一个方法去逐一匹配, 因为这个要求较少, 但是如果要求身份证号, 或者其他的东西那这个方法就太长了, 而且之后学习到的一些爬虫相关的方法, 比如
pattern  matcher  都需要正则表达式, 所以, 出现了这个更简洁的正则表达式
具体形式如下

正则表达式就是一个字符串, 只不过传递给特定的方法会给你转化成对字符串的匹配要求, 也就是, 你写正则表达式要按照一定的要求
`[a()*-=.]` 重点看这个`[]`这个东西括起来的部分可以写很多东西, 表示你要匹配的文本的这个位置的字符是其中之一, **其实跟 或者 | 意思差不多** 这个例子里面就表示这个位置可以是a (   )  \*  -  =  .  这几个字符, 记住内部表示可以是其中之一, 但是只有几个字符比较特殊, 需要用转义字符才能表示符号本身, 之后再说

{}这个是限定紧邻它的那个整体的数量的, 他一共有三种写法, 
{n}正好n个
{n , }至少n个
{n, m}n到m个, 包括n和m

()这个很好理解, 就是把内部框定成一个整体, 针对某些字符 比如 |  {} 加上()可以指定一个特定的范围, 防止出现问题
不光如此, 这个还有捕获分组的作用, 按照 左括号 ( 的顺序被从1开始划分组, 这个会结合后面的 $ \\\1 ?=   ?!   ?: 来使用

限定范围的特殊符号应该就这几个, 接下来说一些特殊符号
^ 这个符号是取反的作用, 但是必须要写在`[]`的里面的开头才表示取反, 
有的位置还表示锚定字符串, 比如"^java"这个正则就表示在一个字符串中找java这个字符串, 而且这个串必须是原字符串的开头, 啥意思  比如 "java, java, java"有3个java但是只有第一个开头的java能被匹配

?: 这个也是起到匹配字符的作用, 但是这个会让()的产生分组的效果失效
"((?i)java)(?:123)" 这个正则就是会匹配java123这个整体, 用group()拿到的也是java123  只不过
