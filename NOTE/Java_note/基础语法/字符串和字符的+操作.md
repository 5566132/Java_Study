对于一个加法表达式, 如果运算符的两侧存在字符串, 那就会把本次运算转变为字符串拼接
"abc" + 123   ->  "abc123"
"abc" + 3.99  ->   "abc3.99"
由于加法是有先后顺序的所以这个运算符两侧指的是进行完运算的结果
123 + 3.99 + "abc"  ->  "126.99abc"
**我感觉这个运算规则貌似可以理解为如果运算符某一侧存在字符串, 就会把两侧的所有部分都转化为字符串类型,** 
"abc" + true  ->  依旧是字符串 "abctrue"

1 + 2 + "abc" + 2 + 1   ->   "3abc21"

比较特殊的是字符串不是字符
字符的运算会被强制转变成
