## 哈希扰动
static final int hash(Object key) {
    int h;
    // key.hashCode()：对象原生hashCode（int）
    // h >>> 16 ：右移16位，取出高16位
    // ^ 异或：把高16位混合到低16位
    return (key == null) ? 0 : (h = key.hashCode()) ^ (h >>> 16);
}
具体来说, 原生hash值很多情况都会导致高位比较随机, 但是低位都是0, 所以要进行 哈希扰动
也就是不只用低位去计算hash值, 把高位也利用上, 因为hash值是32位的, 所以右移16位,
注意看 >>> 三个小于号, 
java右移的机制是看最高位的值, 如果是正数最高位是0那就会补0, 反之负数最高位是1, 补1
0001 0011  >>>或者>>  4    -> 0000 0001
1001 0011 >>> 4   ->  0000 1001      但是 >> 4  就成了 1111 1001

## 头插和尾插:
头插就是把新加入元素(node0) 另 node0.next = node1;  table`[i]` = node0
在多线程并发的时候在扩容和put()的时候都有问题, 扩容时可能导致成环
put()的时候则可能导致新加入的元素被覆盖
尾插只能解决扩容成环问题, 依旧不能解决put()元素被覆盖问题

**扩容, 利用头插和尾插**
1.扩容要把旧数组的所有元素都加入新数组
2.添加元素头插和尾插都很好理解, 说一下扩容时的头插和尾插
在JDK7之前用的是头插, JDK8之后就都是尾插了
3.扩容的时候会因为hash值不同导致在oldtable相同下标的元素扩容后跑去不同下标
具体地说 hash&oldCap 和 hash&newCap 肯定不一定一样
所以只要把对应地下标放入对应地newtable下标即可

**头插:**
其实非常简单, 可能刚才有点想复杂了
先说添加一个新元素的过程node0
node0.next = table`[i]`
table`[i]` = node0
结束
扩容就是把所有节点都进行这个过程即可
node e = oldtable`[i]`; 
while(e != null){
	node temp = e.next; -> 记录e的下一个节点, 
	e.next = newtable`[i]`;
	newtable`[i]` = e;
	e = temp;
}
结束
需要注意这个是伪代码, 真实要根据hash判断是高位链表还是低位链表进而把当前节点放入对应地newTable下标
**多线程成环:**
假设 A -> B -> null
线程1先 node e = A ,   node temp = e.next(B);
然后线程2抢占cpu并完成扩容 B -> A -> null
接着线程1回来, 让 e(A).next = B , newtable`[i]` = e(A) , e = temp(B);
现在好了, A指向B  B指向A 成环了, 也称死循环了
当然在别的地方被抢占cpu也会导致成环, 这只是一个例子

**尾插:**
添加数据的时候就是遍历链表找到最后一个元素然后把新元素加入到末尾
扩容也是这个机制, 遍历所有节点, 判断高位低位链表, 构造新链表即可
源码是对于高位和低位链表, 分别创建了头节点和尾节点, 先构造出链表, 
再newtable`[i]` = head
这个不会成环, 但是依旧存在数据被覆盖, 你可以自己推


## 重写 hashCode 和 equals 
hashCode就是计算hash值得规则, 对于自定义的引用数据类型要重写去用成员变量计算hash值, 否则就会自动用地址计算导致每一个new的对象都是不同的hash值
equals就是为了用成员比较两个对象是否相同, 不重写就会用地址比较, 
所以 没重写hashCode就会导致两个key内容相同hash值却不同, 没重写equals就会导致存在多个内容相同的key, 也就没了去重的效果
