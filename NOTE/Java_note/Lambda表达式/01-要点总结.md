1.一般都是你调用某个方法的时候发现这个方法的参数是利用一个函数式接口中的方法返回的, 这个时候就可以用Lambda表达式去, 你要注意, 这个时候这个方法要接收的是这个接口的实现类对象, 而这个接口中有一个方法, 这个方法有一个形参, 不是你只需要提供一个返回值给这个方法

## 基本规则
接口中方法大概是
public 返回值 方法名( 形参1, 形参2 );这样的形式, 返回值就是调用的方法的参数
使用Lambda的时候用如下形式代替你调用的那个方法的参数位置:
**(形参1, 形参2) -> {接口方法重写的内容}**

注意点:
1.如果形参只有一个可以省略() 
2.方法体只有一行可以省略{} 和 return 还有 分号;
形参1 -> 形参1    意思是直接把新参1返回
