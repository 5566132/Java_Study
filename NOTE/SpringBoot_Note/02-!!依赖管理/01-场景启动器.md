## 场景启动器
```
<dependency>  
    <groupId>org.springframework.boot</groupId>  
    <artifactId>spring-boot-starter-web</artifactId>  
</dependency>
```
依赖中的`<artifactId>spring-boot-starter-web</artifactId>`就是场景启动器
官方打包好的基本都是spring-boot-starter-`*`的形式

#### 场景启动器存放**某个场景所需的所有依赖和默认配置**的一个依赖
1.这个场景启动器也是个依赖, 也需要有版本的
2.比如这个`spring-boot-starter-web`中就存放了web开发所需的所有依赖, 并配置好一些默认配置 , 所以, 你没导入tomcat依赖却可以用它去监听端口然后接收web请求, 就是因为已经在这个web场景启动器中给你导入好了


## 为什么没写版本??
以前见过的依赖都是写有版本的\<verson>.......
但是这个没有, 为什么
这是springboot的特质
```
<parent>  
    <groupId>org.springframework.boot</groupId>  
    <artifactId>spring-boot-starter-parent</artifactId>  
    <version>4.1.1</version>  
    <relativePath/> <!-- lookup parent from repository -->  
</parent>
```
pom.xml文件中一般都有这么个配置, 其中的
`<artifactId>spring-boot-starter-parent</artifactId>`
这个东西中就存放了各种核心场景依赖依赖的默认版本, 也存放了别的依赖的默认版本
