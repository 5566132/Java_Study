### 🔴 第 0 步 · Java 8 补漏

> ⏱ **3-5 天（12-16h）** ｜ 📅 **2026-10 上旬** ｜ 📚 B 站搜"Java8 新特性"任选 2h 速通 + 自己写 demo
> **为什么必须现在补**：MyBatis-Plus 的 `LambdaQueryWrapper`、项目里的 `list.stream().map().collect()`、`Optional` 判空，全是这套东西。现在花几小时，后面省几十小时。
> ⚠️ **不用系统学函数式编程**，够用就停。

- [ ] `stream()` 创建：`list.stream()` / `Arrays.stream()` / `Stream.of()`
- [ ] 中间操作：`filter` / `map` / `distinct` / `sorted` / `limit` / `skip`
- [ ] 终结操作：`collect(Collectors.toList()/toMap()/groupingBy())` / `forEach` / `count` / `reduce` / `anyMatch`
- [ ] **方法引用 `::`**：静态方法引用、实例方法引用、构造器引用（`String::new`）
- [ ] `Optional`：`ofNullable` / `orElse` / `orElseThrow` / `map` / `ifPresent`
- [ ] 写一个 demo：用 Stream 把 `List<Emp>` 按部门分组、求平均薪资
- [ ] 笔记落到 `Java_note/` 下（建 `Stream流/` 和 `方法引用/` 目录）

## 五、⚠️ 项目定位（最重要的一节，别搞错）

你的 `02-项目规划` 里两个项目是**留简历用的**。苍穹外卖**不是**，它是"从会语法到会做业务"的过渡桥。顺序必须是这样：

| 顺序 | 项目 | 定位 | 时间 | 塞进去的 Agent 模块 |
|---|---|---|---|---|
| 过渡 | **苍穹外卖** | 练手 · 打基本功 · **不上简历（或只占一行）** | 大二上末 ~ 大二下初 | 智能客服：`@Tool` 暴露订单/菜品 Service |
| 主项目 | **黑马点评**（Redis） | **简历项目** · 面试官爱问 Redis，这个比外卖拉分 | 大二下 | 商户 RAG 知识库 + **Redis 语义缓存** |
| 主项目 | **秒杀系统** | **简历项目** · 高并发，技术话题最丰富 | 大二下 | 成本治理 + 可观测性：限流、Token 看板、Trace |

> 🔗 **Agent 模块的完整规划见 [[13-AI-Agent学习规划]]**。核心原则：**不要新建孤立的 agent demo**，而是挂在已有项目上长出来 → 简历是"Java 后端 + AI 落地"。
> 为什么这么做：2026 年调研显示「有 Agent 项目经历」正在从加分项变成事实上的筛选项，但**后端技术栈仍是硬性要求**（校招 JD 里 AI 多为"了解 + 有项目优先"）。

**为什么苍穹外卖不能原样上简历**：2026 秋招反馈是它已"烂大街"，牛客和 linux.do 上大量"用这个很难约到面"。**拿它练手 100% 没问题**，但投简历前至少要：
1. 二开到 JDK 17 + SpringBoot 3（`javax` → `jakarta` 迁移经历本身就是面试素材）
2. 修掉原项目源码 bug
3. 把 Redis 部分讲深（缓存一致性、分布式锁、穿透/击穿/雪崩）

> 判断标准：**"跟着敲完" ≠ "项目"**。不看视频能重写 + 能连续讲 30 分钟 + 能回答追问，才算。
