## properties只能用k=v的形式配置

比如 spring.application.name=boot3-1-demo


## 在yaml中只能使用k: v 的形式配置

前面的自动配置类提到了, 自动配置了可以和 属性类 绑定, 从属性类中获取值去给自动配置类中的bean注入属性 , 
然后属性类可以和 yaml文件绑定, 绑定的时候是用@ConfigurationProperties注解去指定用什么前缀可以给当前属性类中的属性赋值,可以看一下例子[[05-属性类]]

yaml配置格式比较特别, 可以用层级形式配置
比如在properties中的配置
```
spring.data.redis.port=8888
spring.data.redis.host=localhost
spring.what.url=666
```
在yaml中可以如下
```
spring:
  data:
    redis:
      port: 8080
	  host: localhost
  what:
	url: 666		
```
看懂了吧, 就是左边对齐的奇怪配置方式
#### 重点
1.左侧的缩进不可以使用TAB, 只能手打空格, 
2.值和冒号之间必须有空格 port: 8080
3.缩进几个空格无所谓, 但是同级的属性缩进格数一定要相同

当然,也有别的方式, 但是可能更麻烦一点
