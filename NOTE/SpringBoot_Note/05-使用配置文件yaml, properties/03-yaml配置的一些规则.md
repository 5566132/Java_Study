### 我要说一下java中字符串到底层的具体规则
首先, 你在java代码中写的字符串和字符串用二进制存到底层是完全不同的东西
你熟悉的那个java代码中的转义只在java代码中生效, 到了底层\n就是\n回车就是回车
具体来说, 对于name这个变量
你想要在java代码中输出 小明\n小八 就必须让name存在底层的那个表达形式是
小明\n小八 
放在java代码里面就要 `name = "小明\\n小八"`
如果写成 name = `"小明\n小八"` 那在底层存的就是回车


value可以是 直接写内容  单引号  双引号
name: "小明 \n 小八"
name: '小明 \n 小八'
name: 小明 \n 小八

其中 单引号 无引号 都相当于把这个内容直接存到底层
双引号就直接使用java代码的存储字符串的规则
```
//所以双引号输出就是
小明
小八

//另外两个输出就是
小明\n小八
```
