直接在yaml中基本就能配置日志相关的所有东西
比如,全局默认使用的日志权限级别
指定包配置日志权限
日志的输出格式等
## 设置包的日志权限
```
#默认所有日志没有精确指定级别就使用root的默认级别
#logging.level.root=info

#精确调整某个
logging.level.com.atguigu.logging.controller=info
```

## 设置分组
把几个包放入同一组, 之和可以直接调整组的权限级别去更改组内所有成员的权限级别
```
//划分组别
logging.group.aaa=com.heima.A, com.heima.B, com.atguigu.A

//更改一组的级别
logging.aaa=info
```


# 日志写入文件
写入文件可以做持久化保存, 日志就一直存在了
```
logging.file.name=demo.log
//或者
logging.file.name=D:\\demo.log
```
1.不带路径就生成到当前项目同位置下
2.带路径就生成到指定路径下

## 归档
其实就是
logging. logback.rollingpolicy. file-name-pattern=${LOG_FILE}.%d{yyyy-MM-dd}.%i.gz
