自动配置类位于spring-boot-autoconfigure中的一个包下面
用**这个@AutoConfiguration注解**去标注的, 
还标注有条件注解, 这个是为了适应场景的, 也就是会在特定场景才生效
一般叫做xxxAutoConfiguration
而自动配置类中属性是依靠**属性类**注入的, @xxxProperties注解
这个两个东西位于spring-boot-autoconfigur下的同一个子包下面

```
//注解为自动配置类
@AutoConfiguration
//设置条件, 满足某种条件才会被注册成bean
@ConditionalOnClass(RedisOperations.class)
//跟 属性类 绑定
@EnableConfigurationProperties(RedisProperties.class)

@Import({ LettuceConnectionConfiguration.class, JedisConnectionConfiguration.class })

public class RedisAutoConfiguration {
...
}
```
