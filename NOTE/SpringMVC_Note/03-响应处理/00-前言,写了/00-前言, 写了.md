对于客户端的请求报文, 服务端一定会返回给客户端一个响应报文
这个响应报文没有方法体(method)和URL, 也不一定有请求体
大概格式如下
```
状态行
响应头1
响应头2
...
（一个空行！！）
【响应体（可选，可以直接省略）】
```
```
HTTP/1.1 302 Found
Location: http://localhost:8080/index.html
Server: Tomcat

←空行，后面没有响应体
```
其中状态行中可以存放400等状态信息, 但是如果只需要传递少量信息可以选择在
Location响应头传递, 比如这个302就是告诉客户端要跳转, 跳转到Location的链接
对了, 请求头和响应头还是有区别的
