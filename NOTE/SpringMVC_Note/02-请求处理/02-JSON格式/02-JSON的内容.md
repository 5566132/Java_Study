JSON的内容都是 "名称":类型 这个格式的
具体的类型分为如下
1.字符串
"username":"小明"

2.数字
"age":18       "pro":3.8

3.布尔类型
"isEnglish":true

4.数组
"arr":`[]`

5.对象
"class":{}

6.空值
"age":null
这些只是在JSON里面的表达形式, 实际上用代码接收会有一些兼容
比如String 类型能接字符串, 数字, 布尔, 空(包装类本来就能接呀)
你只要知道被双引号包裹上的value就会变成字符串, 字符串不能乱传
比如Integer只能接收null/数字     int只能接收数字
其实没啥, 根据理解注意哪些类型都能被哪些接收就好
```  
{  
    "username":"你好",  
    "age":20,
    "isStudent":true,
	"arr":["12", 13],
	"cl":{
	"age":"12",
	"name":"小子"  
    }
}  
```
这是我写的一个json, 正常里面就这么写, 你看, 那个数组类型, 写成"12"或者12都可以,
这个json转对象其实是底层先把json转成字符串, 没错就是整个文本都变成String, 然后用这个字符串去给对象赋值
