参数( param ), 就是?后面那些
这个参数是指GET报文写在URL里面的参数
`localhost:8888/handle01?username=1&password=1&cellphone=1&agreement=on)`
这些参数本质就是键值对

1.用形参接收
这个可以把参数名直接作为响应体的形参对象名, 但是名字要完全一样, 类型用String就行
就是在形参上写 String username 这个username要跟URL上的参数名一样, 接收到的就是后面的值

2.@RequestParam注解
这个注解是写在形参上的, 刚才那个方法要求形参名一定要跟参数名相同, 但是用了这个注解就可以指定这个形参接收的参数叫什么名, 也就是形参名和参数名可以不同, 而且还能指定一些别的属性
@RequestParam( value = "username", required = false , defaultValue = "xiao" )
value设置参数名, 
required设置该参数是否必须存在, 为false代表报文中可以没有这个参数
defaultValue设置传递给响应体的这个参数的默认值, 如果required设置为false那报文可以不存在这个参数, 那这个参数就是null或默认值了, defaultValue可以手动设置默认值

**3.用类对象接收**
创建一个类有这几个参数字段, 成员名要一样, 并且要有get和set方法
然后把类对象作为形参传递, 会自动把URL的参数赋值给对象的参数, 而且不存在啥的情况都会自动处理好
因为这个方式本质就是名称匹配然后赋值呀, 没有就直接为空或者默认值就好了, 但是如果你想要检验某个参数存在就必须要特殊检验, 之后会学吧, 现在先知道有这个东西


4.依旧可以接收全部参数
@RequestParam Map\<String , String> param
