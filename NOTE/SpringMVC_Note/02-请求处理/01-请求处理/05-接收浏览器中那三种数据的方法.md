```
Content-Type: application/x-www-form-urlencoded; charset=UTF-8
```
键值对形式, 其实学到这里你可以理解键值对主要就是用key去接value, 
所以可以用同名变量接值, @RequestParam("key的名称") , 类这三个方法去接收值

```
Content-Type: multipart/form-data; boundary=----WebKitFormBoundaryxxxx
```
这个把数据分块了, 只是为了底层能识别那部分是什么形式, 你接收数据依旧可以用那三个方法去接收 同名形参, 类, 注解不同名形参
但是注意, 二进制的内容要用 SpringMVC提供的MultipartFile[[06-接收二进制文件MultipartFile]]这个类型去接收, 其他的规则都知道的差不多
