注意, 请求行下面的所有 a:b 形式的每一行都属于请求头
基本都是用注解指定value去获得内容的
@RequestHeader
这个注解和获取请求参数那个是很类似的, 都是用于形参, 都可以指定必要性, 默认值
但是这个不能用类接收
@RequestHeader(value = "Host" , required = true,  defaultValue = "666") String host
可以在响应体的形参这么写一个参数,
value代表请求头的名称, 这个可以忽略大小写

特例
Cookie
这个请求头的格式是
Cookie:  key1=value1;  key2=value2;  key3=value3 
获取这个请求头的时候要用
@CookieValue("key1") String str
去指定把Cookie请求头中的哪一个key的值赋值给形参

## 总结
**请求头的获取必须要加上@RequestHeader注解,** 
**@RequestHeader("Host") String host 可以获取单一指定的请求头,** 
**@RequestHeader Map\<String, List\<String>> headers 可以获取全部请求头**
