封装响应体用一个泛型类去封装 R\<T>
内部有 Integer code 指定本次操作(注意是操作, 不是HTTP状态 )的状态码, 告知前端这个信息让前端更好处理
String msg 封装一些信息, 
T data 泛型的数据, 可以接收各类信息, 比如单个类对象, List数组等

然后内部再封装静态方法去初始化这些信息, 根据Controller中的方法调用不同的R中的静态方法 ,   
比如成功调用可以 R.ok();封装成功的信息
出异常可以 R.exc();之类的

**注意这个封装的只有响应体的内容, 虽然跟HTTP长得类似 , 有状态码, 内容,** 
**但是这些东西都是针对操作数据返回给前端的信息, HTTP是针对前后端的通信**
**思想类似, 但是对象不同**
