## 业务异常类
方便传递所有异常而把所有异常划分到这一个异常范围, 更注重用状态码, 和消息传递异常的信息而非用异常本身
```

public class BizException extends RuntimeException{

	//这里可以直接用lombok的@Getter自动生成get方法, 否则就手写
	@Getter
	private Integer code; -> 异常状态码
	@Getter
	private String msg; -> 异常消息
	
	//试想, 如果不使用异常枚举类代替形参, 每次抛出异常都要new, 
	//而每次new都需要手动填上这两个参数的具体值, 异常多了, 维护成本就高了
	public BizException(Integer code , String msg){
		super(msg);
		this.code = code;
		this.msg = msg;
	}
	
	//异常枚举类作为形参
	public BizException(BizExceptionEnum e){
		super(e.getMsg());
		this.code = e.getCode();
		this.msg = e.getMsg();
	}
	
	

}

```

## 异常枚举类
这个就是用来存放所有异常信息, 包括异常对应的状态码code和消息msg, 这样存储就类似建立了业务异常名称和信息之间的映射关系, 无需每次抛出异常都将code 和 msg 作为参数传递而是传递他们的类似键的东西
```
//异常枚举类
public enum BizExceptionEnum{
	ORDER1(10000, "一号异常"),
	ORDER2(10001, "二号异常"),
	ORDER3(20000, "三号异常");
	
	@Getter
	private Integer code;
	
	@Getter
	private String msg;
	
	BizExceptionEnum(Integer code , String msg){
		this.code = code;
		this.msg = msg;
	}
}
```
之后直接传递 BizExceptionEnum.ORDER1就能用get获得code和msg
