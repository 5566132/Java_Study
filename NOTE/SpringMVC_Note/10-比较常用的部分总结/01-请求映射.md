## 请求映射
顾名思义, 根据前端发来的请求路径去映射后端Controller中的方法 , 也就是请求映射方法
`http://localhost:8080/api/v1/employee`
主要关键字
## @RequestMapping( value = "" , method = "" )
value 指定路径 , 也就是IP后面的部分, /api/v1/employee
method 指定本方法可以接收的请求的方法字段( GET POST DELETE 等)
这个是最通用的, 任何请求依靠这个都可以接收
但是, 根据RESTful接口设计标准, 特定的方法最好用特定的请求映射去注解, 所以有了如下的几个请求映射

只有value一个参数的话, 可以省略掉value
@GetMapping( value = "" )  

@PostMapping("employee")

@Put

@Delete
这些只是软性规定, 更方便定位方法的职责, 不写用RequestMapping指定清楚也可以
根据前缀单词可以看出都接收什么类型的请求
