URL ->  `https://ip:端口号/路径`
首先@RequestMapping只能指定客户端访问服务端的路径, 也就是上面那个URL中的路径位置, 那不对呀ip和端口号都没有, 其实端口号根据https://是有默认值的
那没ip也没法发送报文呀, 事实上, 那个什么TomCat会根据你的application.properties文件中的配置去找ip和端口号, 这个类似于是自动配置的, 也就是不用你的服务端代码管, 直接去配置文件就行
```
# application.properties

# 1. 修改端口（默认8080，改成你想要的，比如8081）
server.port=8081

# 2. 监听地址！重点！
# 写 127.0.0.1 / localhost：只能本机访问，外部电脑、手机连不上
# 写 0.0.0.0：监听本机所有网卡，局域网/云服务器外网都可以访问
server.address=0.0.0.0
```
文件大概就这么配置
所以, @ResquestMapping只需要配置需要的部分即可
