如果类成员含有引用数据类型有三种注入方式

## 外部bean
比如Student内部有一个Teacher类
可以先写个Teacher的bean, 然后用ref给这个bean注入Student
\<bean id = "teacher1" class = "com.class1.Son_map.Teacher">
	\<property name = >
		\<ref bean = "Teacher bean的id">\</ref>
	\</property>
\</bean>

## 内部bean
就是把Teacher的完整的bean写在property的内部, 相较于完整bean除了id都不能少写

## 级联注入
首先用这个方式要先存在一个外部bean, 这么说这个方式就起到一个给bean的属性重新赋值的效果呗
然后先用外部bean的方式注入, 注入完新开一个property
\<property name = "外部bean的id . name" value = "新的名称"/>
注, 这里依旧可以按照上面那个比较完整的写法去写property和value, 但是我有点懒就直接简写了
