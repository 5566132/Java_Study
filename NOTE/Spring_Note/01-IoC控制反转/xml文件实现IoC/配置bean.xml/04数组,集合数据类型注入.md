其实到现在也能有所发现了, 这堆属性的注入就是一堆关键字的嵌套
要创建对象就要先用bean指定id和类
要给成员赋值就先用个property去指定成员,根据类型不同选择value或者ref bean去注入

数组就是一堆相同类型的数据放在一起了, 所以给数组赋值的时候要
\<property name = "arr">
	\<array>
		一个一个注入
	\</array>
\</property>

集合跟数组差不多, 只是不用array框了, 改成list了, set就改成set呗

Map要写的更多点, 因为Map内部是Entry, Entry内部是Key和Value, 这些都要注入
\<property name = "m">
	\<map>
		\<Entry>
			\<Key>
				\<value>10086\</value>
			\</Key>
			根据Value是否是引用数据类型选择用value还是ref bean
			当然, 这里也可以写外部bean注入, 内部bean太长了
		\</Entry>
	\</map>
\</property>
