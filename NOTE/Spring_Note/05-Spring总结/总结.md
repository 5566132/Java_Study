首先ApplicationContent这个接口就是容器的化身, 创建了这个接口的实现类对象之后可以用对象创建容器中的bean
ApplicationContext ac = new ClassPathXmlApplicationContext("bean.xml");

**ApplicationContext ac = new AnnotationConfigApplicationContext(SpringConfig.class);**

spring中大概有两类东西, 
一类是bean, 另一类是外部文件
**外部文件**
就是 .properties后缀的文件, 如果想要引入就要用xml扫描或者配置类@PropertySource去导入

**Bean**
这个其实就分两个方式, 一个是用xml文件, 一个是用配置类
这两个方式区别在于传递给容器对象的参数不同, 配置方式不同, 但是都需要利用其他注解去辅助实现

**用xml就把 .xml 文件作为参数在创建容器对象的时候传给它**
一般是开启组件扫描, 把扫描到的组件注册成Bean, 需要给某些bean注入容器中的bean的时候直接在xml里面用 ref bean = 注入即可, 切面类也是通过在xml里面开启扫描去扫描到的

**用全注解**
主要是利用@Configuration去注解类, 然后把扫描, 引入外部文件, 内部配置类都写在这个类中
扫描用@ComponentScan("包路径")
引入外部文件@PropertySource("路径")
内部配置写在配置类的里面
用@Bean注解
**内部配置的时候有个关键点, 写在方法形参上的参数容器会自动去找对应的Bean进行注入,** 类似于隐式使用@Autowired, 先类型, 后名称, 当然也可以用
@Qualifier("指定bean的id注入")
