我其实是可以在Service去构建LambdaQueryWrapper这类东西的, 然后利用这个去进行查询, 就用这个4举例
这个4要传递一个List\<Long>集合, 那么我如果直接用xml就需要使用\<collection标签去实现, 但是要是我在Service层把这个List的条件转化成where条件, 也就是
```
LambdaQueryWrapper<User> lqw = new LambdaQueryWrapper<User>()  
        .in(User::getId, list);
```
这样, 就可以不用标签, 直接在xml中把这个wrapper传递即可
#{ew.customSqlSegment}  -> where id in(1,2,3......)
