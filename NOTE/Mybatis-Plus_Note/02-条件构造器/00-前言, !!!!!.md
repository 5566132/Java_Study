说条件构造器之前, 我可以总结一下Mybatis和Mybatis-Plus的优缺点, 有助于理解何时用什么
首先MP本身就是对Mybatis的增强, M的基本功能依旧不变, 只是可以利用MP让更多事情更方便
### Mybatis
1.创建类
2.创建Mapper接口
3.创建xml文件关联接口和类
这三者缺一不可, Mapper提供特定方法的模板为代理类做准备, xml提供Mapper中方法的具体实现内容, 类作为载体装载数据

### Mybatis-Plus
1.简化了基础sql语句, 就是那些限制很少甚至没有限制的sql, 这些只需要你写了Mapper接口, 存在对应的类(类要用注解配置好和表中字段的关联)就可以直接用这类简单sql
2.较复杂且只针对单表的sql需要用到条件构造器, 比如只查询某些字段, 
set age = age + 20这类sql需要利用条件构造器去书写关键部分, 但是既不是手动拼接, 也无需书写xml文件, 可以说是规避了风险, 同时简化了代码
3.面对更复杂场景, 比如涉及到多表查询 left join 等, 很难只用MP的内容实现, 依旧需要xml手动配置

# 总结
MP只是让简单的sql无需繁琐的配置, 但是面对复杂sql依旧需要xml实现
