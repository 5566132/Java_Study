其实在Mybatis中好像没有指定表名这一步, 因为xml文件是针对Mapper接口配置的
而这个接口本身就是专门为某个表设计的操作台, 
Service层, Controller层就是操作这个Mapper去间接操作这个Mapper背后的那张表的, 因为xml中的sql基本都是针对同一张表吧, 

#### 所以我们可以梳理一下Mybatis中各个部分的关系
1.基于表, 我们会在java有一个专门的类去存储这个表的数据, 也就是可以将表中每行数据映射为一个类对象
2.Mapper接口默认是只会操作一张表的, 所以这个Mapper接口也像是表数据和类之间转化的桥梁

但是, 到了Mp中, 我们可以不去为Mapper接口配置xml文件, 而是用注解去达到同样的效果, 但是前提是Mapper继承了BaseMapper\<>接口[[01-BaseMapper接口]]

### @TableName("tb_user")
这个注解是标在User类上的, 也就是绑定了 User这个类是要和tb_user表相映射的

### @TableId(value = "" , type = IdType.AUTO)
这个注解用于类成员上, 但是要用在主键字段对应的类成员上, type用于设置添加类到数据库时是自增还是用set注入后把这个id直接填入数据库

### @TableField()
这个作用于类成员, 
1.可以设置本成员与数据库中字段的映射关系
value = "数据库字段名"
2.可以设置成员是否需要与数据库字段映射
exist = false -> 该成员不是数据库字段
