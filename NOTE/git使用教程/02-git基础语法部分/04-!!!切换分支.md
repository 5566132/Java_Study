分支就是跟master同级的类似指针的东西, 这玩意会指向一个版本, 一般来说都会规定main是上线的版本, 移动main分支的时候需要被审核(github中有开启审核的设置), 而对于个人来说都是基于非main分支去操作的, 所以就要知道如何去从main分支创建,切换分支, 以及如何跳转到指定分支

## switch
切换, 创建都可以只用这一个指令, 只是参数有区别

#### 查看分支记录
git branch 会显示当前仓库都有哪些分支

### 创建并切换分支
git switch -c f1 创建f1分支并切换到这个分支, 会在当前分支指向的这个提交上去创建一个新的分支, 然后让这个新的分支指向当前所在的这个分支指向的提交

### 切换分支
git switch f1 切换到f1分支, 没有就报错
