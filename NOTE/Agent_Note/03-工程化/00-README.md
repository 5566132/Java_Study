## 学习清单

### 必做（★ = 简历差异化点）

- [ ] ★ **手写 ReAct Agent Loop**（不用框架）：思考 → 行动 → 观察 → 循环，直到满足终止条件
      - 必须理解：**终止条件怎么设？循环次数上限？失败怎么办？**
- [ ] ★ **MCP Server**：把你的 SpringBoot 服务封装成 MCP Server
      - 2025-12 MCP 捐给 Linux 基金会，已成工具集成事实标准，10000+ servers
- [ ] ★ **评测 Evals**：建测试集 + LLM-as-judge + Bad Case 分析（国内 JD 已直接要求 evals）
- [ ] **可靠性工程**：重试 / 超时 / **幂等** / 限流 / 降级 / 状态检查点（← 你的强项）
- [ ] **可观测性**：Langfuse / LangSmith —— Trace、Token 成本、延迟
- [ ] **成本优化**：模型分层（规划用大模型 / 执行用小模型）、KV Cache、批处理

### 了解（⚪ 别投入时间）

- [ ] LangGraph（Python）编排
- [ ] 多智能体模式：Supervisor / Handoffs / Routing
- [ ] vLLM / Ollama 推理服务化
